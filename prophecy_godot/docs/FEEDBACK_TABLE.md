아직 해결하지 않은 불일치 두 가지:

| 항목 | 지금 | 새 설계 | 상태 |
|---|---|---|---|
| 쌍륜(회전 칼날) | "세 번째 칼날" — 기본 2개에 +1 | 반대편에 하나 추가. **최종 개수를 명확히** 하고 개별 피해를 낮추며 범위를 넓힌다 | 대기 |
| 도약 지뢰(룬 지뢰) | "유인 룬" — 작은 적을 당긴다 | 가까운 적에게 **짧게 도약해** 폭발. 유인은 도깨비 인형이 담당 | 대기 |
| 감전 부여(번개 구체) | ~~개조 '축전'을 골라야만 감전이 붙는다~~ | **기본 연쇄가 감전을 부여**하고, 축전은 "감전 후속을 쌓으면 방전"이라는 별개 효과 | **완료** |

그쪽이 병합된 뒤에 처리한다. **옛 저장은 기존 효과를 보존하고 조용히 다른 개조로 바꾸지 않는다.**

## 5. 증강을 '찍은 뒤 전투가 달라지는 효과'로

기존 효과의 발동 자격을 새 구조에서 다시 확인했다(`tests/support_tests.gd` 10절).

| 증강 | 새 구조에서의 문제 | 처리 |
|---|---|---|
| 무기 공명 | 자리가 딱 3개인데 수호 방울·가시 갑각·도깨비 인형은 직접 피해가 없어 **영원히 못 터진다** | 자격을 "공격 출처 3종 이상"으로. 안 되면 후보로 내지 않고, 카드에 지금 몇 종인지 적는다 | **완료** |
| 시간의 복제 | 무기 종류를 손으로 나열해 추격 까마귀·역병 나비가 빠져 있었다 | 카탈로그 분류로 판정. 되돌림 반격탄도 투사체로 센다 | **완료** |
| 연쇄의 씨앗 | 독(역병 나비·독가시)이 상태 이상으로 안 세어졌다. 보조로 든 서리 수정의 냉기도 빠졌다 | 둘 다 공급원으로 넣었다 | **완료** |
| 불꽃 파열 | 불씨가 보조가 돼도 전제(`common:ember` 또는 `weapon:ember`)가 그대로 성립 | 확인만, 변경 없음 | **완료** |
| 정지된 칼날 · 시간 저축 | 감속장(Q) 전제라 구조 변경과 무관 | 확인만 | **완료** |
| 일제 공격 | E 전제라 구조 변경과 무관 | 확인만 | **완료** |

아직 안 한 것: 단순 수치 변화에 머무는 후보를 **행동 변화**로 보완하는 일
(망치 강타 처치 → 여진, 쌍검 감전 연타 → 축적 방전, 둔화된 적 강타 → 파편, 감염된 적 우선 처치 → 전염·파열).

**허용해야 할 연쇄와 막아야 할 오류를 구분한다.**
다른 적이 실제로 죽어 다음 처치 효과를 일으키는 것은 정상이고 재미의 핵심이다.
막는 것은 같은 적의 사망 중복 정산 · 감전의 자기 호출 · 반사의 자기 호출 · 분신의 무한 복제뿐이다.
전염 세대 상한 2도 시험값이며 연쇄 체감을 얼마나 줄이는지 확인해야 한다.

## 6. 검증 원칙

- **전체 통과 숫자가 UI 가독성이나 사람의 재미를 증명하지 않는다.** 사람이 봐야 하는 항목은 따로 목록으로 남긴다.
- 옛 보고서 수치를 진행 중인 변경에 그대로 붙이지 않는다.
- 평균 하나로 뭉개지 말고 일반 적 · 방패병 · 정예 늑대 · 특수 정예를 구분한다.
- 봇이 새 물약·증강·표적 선택을 이해하지 못한 실패는 **콘텐츠 난이도와 구분**한다.
- **KD-1**(단언 통과 뒤 종료 실패)과 **KD-6**(부하에 따른 검사 흔들림)은 별개로 추적한다 — `docs/KNOWN_DEFECTS.md`.
- 보고는 **단언 통과 수 · 정상 종료 수 · 종료 실패 수**를 분리한다.

## 7. 지금까지의 대표 조합 측정에서 나온 것

`docs/sim/COMBO_PROBE.md`(대표 조합 7개, 봇 2종 × 시드 3). **모든 조합의 대규모 시뮬레이션이 아니다.**

첫 실행에서 역할 지표가 전부 0으로 나왔다. 콘텐츠가 약해서가 아니라 **A조·B조가 각자 다른 이름으로
세고 있어 측정이 읽지 못한 것**이었다(`PSupport.sync_meters`로 이름을 맞춰 해결).

지표를 연결한 뒤 드러난 것:

| 발견 | 판단 |
|---|---|
| **번개 구체가 감전을 안 걸었다 → 해결** | 코드를 읽어 확인했다: 감전(`conduct`)은 **개조 '축전'을 골랐을 때만** 붙는다(`weapons.gd` 372행). 사용자 확정은 "**번개 구체의 연쇄 공격으로 감전을 부여한다**"이고 축전은 "감전 후속을 쌓으면 방전"이라는 별개 효과다. 지금 구현이 둘을 합쳐 놓았다. 대표 조합의 `shock_procs 0`은 그 결과다 — 봇 문제가 아니다. **고쳤다.** 기본 연쇄가 감전(2.0초)을 부여하고, 축전은 '감전 후속 3회 → 방전'이라는 별개 효과가 됐다. 측정: 감전 부여 48 · 후속 발동 37 · 후속 피해 441.3(이전 전부 0) |
| 도깨비 인형 | **해결.** 유인된 적이 인형을 향해 이동만 하던 것을 **사거리 판정·조준·공격·피해 적용까지** 연결했다(`CombatState.target_of`). 이제 인형이 실제로 대신 맞는다: 유인 13 · 대신 받음 3회(36 피해) · 본체 피격 7회→3회 · 본체 피해 84→36. **적이 멈춰서 피해가 줄어든 것이 아니다.** |
| 잔영 분신: 21~24번 발동, 피해 36~42 | 발동은 정상. 피해가 작은지는 다른 보조와 같은 조건에서 비교해야 판단할 수 있다 |
| 바람 정령: 밀어낸 거리 566(실력)·1170(초보) | 정상 작동. 초보 봇이 더 많이 밀어낸다 = 적이 더 붙는다는 뜻 |
| 역병 나비: 전염 9~12회, 파열 0 | 전염 정상. 파열은 개조를 안 골라서 0이다(조합이 '넓은 전염'을 골랐다) |
| 가시 갑각: 반격 1~5회·경감 3.4~17.5 | 정상 작동. 실력 봇은 맞지 않아 거의 발동하지 않는다 |
| 수호 방울: 차단 0~1회 | 이 편성에서 막을 수 있는 투사체가 플레이어에게 거의 닿지 않는다. 궁수가 많은 편성으로 다시 재야 한다 |
| 기존 보조 5종(칼날·구체·서리·불씨·지뢰) | 내부 계수기가 없어 **계측 미연결**. 표에 그렇게 적히며, **0을 약하다고 읽지 않는다** |

**지표가 0일 때 '봇이 못 쓰는 것'과 '콘텐츠가 약한 것'을 구분해 적는다.**

## 11. 사람이 판단해야 하는 것 (측정으로 답이 안 나온다)

- **쌍검 중첩이 화면에 안 보인다.** 몇 겹인지 모르면 "붙어 있어야 이득"이 손에 안 잡힐 수 있다.
- **일반 탐험 고침의 뒷면**: 같은 카드를 정상 비용에 사건까지 받으며 반복하던 길이 막혔다.
  하루 벌이가 줄어드는 방향이라 금화·경험치 총량이 사람 눈에 어떤지는 플레이로만 안다.
- **관문 사망 뒤 부활의 실제 비용**: `PRun.start_boss`가 입장 때 체력을 완전 회복시키므로
  25% 감점은 실제로 물리지 않는다. 실제 비용은 물약 1개(220금) + 그날 남은 시간이다.
- **약점 보완형 조합 5개 중 3개가 보스에서 무효**(밀어내기 저항 0 · 작은 적만 · 근접 피격만).
  "약점 보완이 가장 필요한 자리에서 가장 약하다"가 의도인지 아닌지는 설계 판단이다.
- **냉기·독은 소비자가 없다.** 감전만 공급 1 : 소비 5로 이어져 있다. 채울지 말지는 설계 판단이다.

**이 문서의 어떤 수치도 재미·균형 승인이 아니다.** 봇 결과로 승인하지 않는다.

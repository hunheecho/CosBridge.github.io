# 중력핵(E) 측정 — 실제 전투에서 센 값 (godot-0.7.0)

생성: `tools/gravity_probe.gd`. 전체 실행(부분 실행 조건 없음).

읽는 법 / 세지 않는 것

- 모든 값은 규칙 안에서 실제로 일어난 사건을 센 것이다(읽기 전용 훅 `PSkills.probe`). 판정·수명·피해를 바꾸지 않는다.
- **간접 기여를 추정 피해로 만들어 총 피해에 더하지 않았다.** '끌어모아서 자동기술이 더 맞았을 것'은 이 표에 없다.
- 중력핵은 도구형 기술이다. 자동기술과 DPS가 같아야 할 이유가 없으므로 '비중'은 목표치가 아니라 관찰값이다.
- 보스는 끌리지 않는다(`scripts/rules/skills.gd`). 보스 장면(boss1~3)의 '끌어모은 적'은 보스를 뺀 잡몹 수다.
- 봇(balanced) 조작이며 사람 실력·재미가 아니다. **전부 시험값이고 밸런스 승인이 아니다.**

장면: `forest` 1일차 근교 숲 일반 조우(1막 기준 빌드) · `ridge` 2일차 능선 일반 조우(1막 기준 빌드) · `marsh` 4일차 습지 일반 조우(2막 기준 빌드) · `deepdive` 7일차 심층 더 깊이(3막 기준 빌드, 정예 섞임) · `boss1` 1관문 보스(끌리지 않는 상대) · `boss2` 2관문 보스(엄폐·수호자) · `boss3` 3관문 보스

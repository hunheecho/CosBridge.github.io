# 성장 구조 변경과 몬스터 체력 재조정

> **2026-09-08 갱신**: 사용자가 성장 구조를 다시 정했다(주무기 1개 Lv5 + 개조 2, 공통 보조 2개 각각 Lv3 + 개조 1).
> 아래 R과 H3은 **그 이전 구조**에서 잰 값이라 잠정값이다. 새 구조의 세부 설계를 받으면 R부터 다시 잰다.
> 지금 값을 되돌리지는 않는다 — 사람 플레이 판단 없이 수치를 오가게 하지 않는다.

2026-09-08. 사용자 승인 방향: 기술 레벨 강화의 가치를 높이고, 개조 개방 Lv2/Lv4와 자동기술별 대장간 강화를 시험한다.
결정 기록은 `docs/DESIGN_DECISIONS.md` D45. **여기 수치는 전부 시험값이며 사람이 승인한 균형이 아니다.**

## 1. 무엇을 바꿨나

| 항목 | 전 | 후 |
|---|---|---|
| 자동기술 레벨 배율 | 1 / 1.2 / 1.4 / 1.6 / 1.8 | **1 / 1.35 / 1.8 / 2.35 / 3.0** |
| 개조 자격 | 레벨과 무관(처음부터 2개) | **Lv2에서 첫 개조, Lv4에서 두 번째** |
| 대장간 강화 | 전체 자동기술에 공용 | **고른 자동기술 하나**에만 |
| 자동기술 슬롯·최대 레벨·개조 수 | 3 / Lv5 / 2 | 그대로 |

같은 조건에서 **기초 피해** 비는 Lv1 1.000 · Lv2 1.125 · Lv3 1.286 · Lv4 1.469 · Lv5 1.667이다.
이것은 빌드 전체 DPS 증가율이 아니다. 개조가 뒤로 밀리고 대장간이 한 기술에만 붙어 **초반에는 오히려 약해진다**(아래 측정).

대장간 비용 단계는 회차 전체에서 이어진다(기술마다 처음부터 싸게 시작하지 않는다).
옛 저장의 전체 강화는 **그대로 유지**되고, 다음 강화부터 고른 기술에만 붙는다. 이미 얻은 개조를 회수하지 않는다.

## 2. 같은 선택 예산에서의 세 정책 비교

선택 1개 = 예산 1. 새 기술 획득·레벨·개조·공용·패시브·Q가 모두 같은 예산에서 경쟁한다.
개조는 자격 레벨을 만족해야 고를 수 있다. 예산이 남지 않도록 세 정책 모두 예산을 끝까지 쓴다.

## 4. 체력: H0 / H1 / H2 / H3을 분리해서 기록한다

중복 상향을 막기 위해 네 단계를 따로 둔다. **H2와 성장 보정을 겹쳐 두 번 올리지 않는다.**

| 단계 | 뜻 |
|---|---|
| **H0** | 0.7.0 이전: `data/enemies.json` 기본 체력 × 등급 배율(1.0 / 1.25 / 1.6) |
| **H1** | 0.7.0 역할별 고정 체력표 |
| **H2** | 사용자 지시 "증가분만큼 한 번 더": `H1 + (H1 − H0)`. 일반 등급은 증가분이 0이라 같은 산식(1막 기준 DPS 22 × 역할 목표 시간)을 처음 적용 |
| **H3** | 성장 보정: `H2 × √R`. **현재 적용된 값** |

후보 셋 중 **완만 보정(√R)**을 기본 시험안으로 골랐다. 근거: ① 측정이 정지 표적 중심의 대용값이라 그대로 곱하면 과보정된다,
② 사용자 지시가 "새 성장 배율을 몬스터 전체에 곱하지 말라"이다, ③ R을 그대로 쓰면 3막이 이미 긴 처치 시간을 더 늘린다.

## 5. 이 보정에서 뺀 것

- **보스**: 일반 적 배율을 자동 적용하지 않는다. 새 성장 상태에서 패턴 도달·정지 전략·회피 빌드로 따로 재측정하고, 바꿀 보스만 근거를 남긴다. 3막 최종 보스의 긍정 평가 방향은 보존한다.
- **제단·봉인 장치 등 구조물**: 임무 길이에 직접 영향을 주므로 별도 항목.
- **경험치·금화**: 이 보정으로 올리거나 내리지 않는다.
- **승인된 첫 전투(D33)**: 오버레이를 적용하지 않는다(`CombatState.reference_fight`). 과거 비교용으로 고정하며, 충돌 버그 수정 결과를 기준표에 맞추려고 수치를 되돌리지 않는다.

## 6. 아직 확인하지 않은 것

- 이 값들이 사람 플레이에서 "너무 빨리 녹는다"를 실제로 해결하는지. 봇 측정은 참고이고 사람 판단이 기준이다.
- 체력만 올리면 오래 쫓아다니는 전투가 된다. 공격 도달·명중·편성 개선과 **함께** 측정해야 한다.
- 방패병 상위 변이 1427은 정면 감소 85%와 겹치면 정면 공략이 사실상 막힌다. 측면·후면 유도가 실제로 되는지 확인이 필요하다.
- 정예 3막 2946은 그 시점 DPS로 약 12초다. 사용자가 제시한 정예 범위(8~15초) 안이지만 위쪽이다.

## 7. 추후 확장으로만 기록(이번 구현 아님)

**Q/E 주력 딜링 트리.** 지금 Q(감속장)·E는 도구·제어 역할이고 성장 선택도 레벨·변형뿐이다.
Q/E를 주력 화력으로 키우는 트리를 넣으면 같은 선택 예산 경쟁 구조가 다시 바뀌므로, 이번 범위에서는 구현하지 않고 여기 적어만 둔다.
넣게 되면 필요한 것: Q/E 전용 개조 계통, 재사용 시간과 화력의 교환, 자동기술과의 선택 예산 경쟁 재측정, 적 체력 R 재산출.

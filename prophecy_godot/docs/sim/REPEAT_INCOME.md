# 일반 탐험 수정(KD-7) 전후의 하루 수입·경험치

- 실행 범위: **전체 실행(축을 줄이지 않았다)**
2026-09-09. **기록 도구다 — 판정 스위트가 아니다**(단언 0/0). 여기 있는 숫자는 전부 봇 결과이고 시험값이다.
**체감·재미는 이 문서가 판단하지 않는다.** 숫자만 낸다.

- 도구: `tools/repeat_income_probe.gd` (스위트 `repeat_income_probe`)
- 대조군 스위치: `PFlow.clear_done_on`(환경 변수 `PROPHECY_CLEAR_DONE=0`이면 옛 규칙). 기본값은 지금 규칙이다.
- 배경: `docs/KNOWN_DEFECTS.md` KD-7 · 규칙: `PSortie.on_clear_win` · `PSortie.repeat_cards`

## 1. 무엇을 고정했고 무엇이 갈라지는가

| 항목 | 값 | 두 규칙에서 같은가 |
|---|---|---|
| 시드 | [1, 2, 3, 4, 5] | 같다 |
| 잰 날 수 | 2일 | 같다 |
| 회차 전략(카드 고르는 규칙) | `gradual` — 1~2일차 숲·능선, 3~4일차 습지·굴, 5일차~ 굴·심층 순으로 선호. 체력 30% 미만이면 휴식 | 같다 |
| 전투 봇 정책 | `balanced` | 같다 |
| 시작 무기 · 밸런스 세트 · 사망 규칙 | sword · 기본 · 시험 재시도 | 같다 |
| **어느 카드를 고르는가** | 전략이 정한 선호 지역 안에서 목록의 첫 카드 | **갈라진다(아래)** |

옛 규칙에서는 이긴 카드가 완료되지 않아 **같은 카드가 목록에 그대로 남는다**(정상 비용·정상 보상·사건 재굴림).
지금 규칙에서는 그 카드가 완료로 접히고, 남는 시간에 **'일반 탐험'(1칸, 전리품·경험치만)** 카드가 생긴다.
봇은 두 규칙에서 **같은 고르는 규칙**을 쓰지만 **목록이 다르므로 고르는 것이 달라진다.**
그 갈라짐 자체가 이 비교의 결과다 — 그래서 출격 횟수·사건 수를 수입과 나란히 적는다.

**왜 2일인가.** 1막 관문은 4일차다. 회차 봇은 하루 고리 맨 위에서 `phase == "boss_prep"`을 먼저 보고
관문을 치르므로(그 뒤에 `max_days` 검사가 온다), 3일을 재려고 하면 3일차를 끝내고 4일차로 넘어가면서
**관문 전투가 금화·경험치·전투 시간에 섞인다**. 그러면 '하루 벌이' 비교가 아니게 된다.
그래서 기본은 관문이 섞이지 않는 마지막 날인 2일이다(`PROPHECY_INCOME_DAYS`로 바꿀 수 있다).

## 4. 이 표가 말하지 않는 것

- **재미와 체감은 재지 않았다.** 하루 벌이가 늘었는지 줄었는지만 있다. 그것이 좋은지는 사람이 정한다.
- 봇은 사람이 아니다. 카드 고르는 규칙 하나(`gradual`)만 썼고, 사람은 남는 시간을 다르게 쓴다.
- 2일까지만 봤다. 관문·후반 날짜의 벌이는 이 표 밖이다.
- 이용권은 보유 기준이라 사용분이 빠져 있다(2절 주석).
- 옛 규칙 쪽 숫자는 **고쳐진 구멍을 되살린 것**이다. 되돌리자는 제안이 아니라 비교 기준일 뿐이다.

# 대표 조합 측정에서 나온 것 (2026-09-09)

`docs/sim/COMBO_PROBE.md`의 표를 읽고 정리한 것이다. 표 자체는 도구가 다시 쓰므로 여기 판단만 남긴다.
**모든 수치는 봇 계측이며 재미·밸런스가 승인됐다는 뜻이 아니다.**

측정 조건: 9일차 수준 편성(늑대 4·궁수 2·방패병 1), 봇 2종(skilled·novice) × 시드 3, 상한 90초.
**계측 미연결은 0건이다** — 보조 12종 전부 지표가 연결됐으므로, 아래의 0은 "재지 못함"이 아니라 "일어나지 않음"이다.

## 잘 작동하는 것

| 조합 | 무엇이 보이는가 |
|---|---|
| 쌍검 + 번개 + 분신 | **감전 후속 32~36회** · 분신 모방 20~22회. 사용자가 확정한 "번개가 걸고 연타가 터뜨린다"가 실제로 일어난다 |
| 창 + 바람 + 지뢰 | **밀어낸 거리 449(실력) / 1358(초보)**. 초보 봇이 더 밀어낸다 = 적이 더 붙는다는 뜻이라 방향이 맞다 |
| 검 + 역병 + 까마귀 | **전염 8~12회** · 까마귀 표적 지정 6~10회 |
| 쌍검 + 갑각 + 방울 | 근접 경감 3.4~13.6 · **반격 1~4회**. 초보 봇에서 값이 커지는 것도 방향이 맞다 |
| 검 + 불씨 + 지뢰 | 불씨 장판 39~42개 |

## 작동하지만 **너무 작아 보이지 않는** 것

| 항목 | 수치 | 판단 |
|---|---|---|
| **수호 방울 차단 0회** | 두 조합 모두 0 | 이 편성(궁수 2)에서는 막을 수 있는 투사체가 플레이어에게 거의 닿지 않는다. **궁수 4기를 세운 장면에서는 1회 막았다**(영상 `sup_bell.avi`). 즉 규칙은 되지만 **평범한 편성에서 체감되지 않는다.** 방울 수·충전 시간 또는 차단 가능 목록을 다시 볼 후보다 |
| **도깨비 인형 대신 맞기 0회** | 유인은 8~10회 되는데 대신 맞기는 0 | 이 편성은 궁수·방패병이 섞여 있어 유인된 적이 인형 앞에서 근접 공격을 하지 않는다. **늑대 10기 장면에서는 1회 대신 맞았다**(영상 `sup_doll.avi`). 유인 자체는 작동하므로 "인형이 일을 안 한다"가 아니라 **"근접이 적은 편성에서는 대신 맞을 기회가 없다"**가 맞는 설명이다 |
| **잔영 분신 모방 피해 0(실력 봇)** | 모방 20회인데 피해 0 | 실력 봇이 계속 움직여서 분신이 선 자리에 적이 없다. 초보 봇에서는 22회에 22.1 피해가 나온다. **봇이 못 쓰는 쪽에 가깝다** — 사람이 자리를 잡고 싸우면 달라질 수 있어 사람 확인이 필요하다 |

## 설명과 다른 것

없다. 다만 아래 둘은 **조건 때문에 0**이며 결함이 아니다.

- **역병 파열 0회** — 이 조합이 고른 개조가 '넓은 전염'이라 파열 개조를 안 달았다. 파열은 `sup_plague.avi`에서 5회 확인.
- **서리 둔화 0회로 보이던 것** — 계측이 없어서였다. 이번에 `slows`를 붙였다(발사 270회는 이미 세고 있었다).

## 사람이 봐야 하는 것

- 방울·인형이 **평범한 편성에서 체감되는가**. 봇 계측으로는 "규칙은 되는데 기회가 적다"까지만 말할 수 있다.
- 분신이 **사람이 조작할 때** 맞는가(봇은 계속 움직여서 안 맞는다).
- 위 판단으로 **수치를 올리지 않았다.** 올릴지는 사람이 플레이한 뒤 정한다.

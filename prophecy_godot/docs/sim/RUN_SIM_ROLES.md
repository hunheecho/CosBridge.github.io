생성: `tools/run_sim.gd` (Godot 4.7.2-stable (official), Windows). 전략 7종 × 시드 1,2. 경험치 필요치 20.0+5.0k+0.1k². 봇 결과는 정책 비교용이며 사람의 체감 플레이타임·재미와 다르다. 머리말 값은 실제 회차·카탈로그에서 읽은 것(F8).

시간 계정(C19): 시뮬레이션된 시간 = 전투 + 보스(고정 단계 시계 1/120초). 가정한 메뉴 시간 = 카드 1장 6초(전투 중 레벨업·지역 3택 포함, 실제 발생 시점에 기록) + 조우 전후 화면 25초 + 사건 8초 + 하루 종료 10초 + 휴식 5초. 합계는 보스전까지 포함해 마지막에 한 번만 더한다. 시간 초과(봇이 조우 240초/보스 300초 안에 못 끝냄)는 패배와 별도 열. 모든 행동은 PFlow.actions(run)의 항목으로만 실행(F1), 조우 생성·정산·3택·사건은 게임과 같은 PFlow/PEvents 경로.

전략:
- 쉬운 지역 반복(easy): 오늘의 카드 중 근교 숲 카드를 고른다(없으면 가장 쉬운 지역). 체력 30% 미만이면 휴식. 더 깊이 없음
- 점차 위험 지역으로(gradual): 1~2일차 숲·능선, 3~4일차 습지·굴, 5일차~ 굴·심층 순으로 선호. 체력 30% 미만이면 휴식
- 위험 지역 우선(risky): 오늘의 카드 중 가장 위험한 지역(심층·굴) 우선. 사건은 제단·상인 구출·봉인 전투를 받는다
- 체력 낮으면 일찍 휴식(cautious): 점진 경로와 같되 체력 60% 미만이면 휴식. 사건은 치료 우선
- 더 깊이 탐험 적극(deep): 점진 경로 + 승리 뒤 체력 50% 이상이면 더 깊이 탐험(행동 목록의 deep_explore)
- 위험 임무 우선(mission): 오늘 카드 중 위험 조건이 붙은 임무 카드부터, 없으면 첫 카드
- 빌드 맞춤 보상 선택(matched): 빌드 연결 카드(보유 무기 레벨·개조·기술) 우선 + 3택은 보유 무기·기술 강화·지역 태그 일치 우선

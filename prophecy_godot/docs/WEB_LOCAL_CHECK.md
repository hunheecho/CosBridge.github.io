# 로컬 웹 빌드 · 실제 브라우저 조작 확인 (2026-09-10)

**외부 배포는 하지 않았다.** `127.0.0.1` 로만 띄웠고, 만든 산출물도 임시 폴더에만 있다.

## 어떻게 했나

1. 웹 내보내기
   `godot --headless --export-release "Web" <임시폴더>/index.html`
   → index.html · index.js(280KB) · **index.wasm(39.5MB)** · index.pck(4.9MB) · 아이콘들
   처음에는 "대상 폴더가 존재하지 않거나 접근할 수 없습니다"로 실패했다 — 폴더를 먼저 만들어야 한다.

2. 로컬 전용 서버
   Godot 웹은 스레드를 쓰면 `SharedArrayBuffer` 가 필요하고, 그러려면 COOP/COEP 머리글이 있어야 한다.
   그래서 파이썬 한 장으로 띄웠다(`Cross-Origin-Opener-Policy: same-origin` ·
   `Cross-Origin-Embedder-Policy: require-corp` · `Cache-Control: no-store`).
   머리글은 응답으로 확인했다.

3. 실제 브라우저에서 눌렀다.

| 무엇 | 결과 |

| 거점 | 대장간·상점·장비·통계/기록·휴식 · 오늘의 출격 2장 · 현재 빌드 · Q 감속장 |

| 새로고침 뒤 '계속하기' | **활성 · "본편 · 10일 · 1일차 · Lv 1 · 금화 60"** · footer "저장 회차: … 시드 41897" |
| 계속하기 클릭 | 거점으로 복귀 · 시간대가 새벽(5칸) → **아침(4칸)** 으로 진행돼 있다(출격이 1칸을 쓴 것과 맞는다) |
| 브라우저 콘솔 오류 | **없음** |

## 확인하지 않은 것

- **안드로이드 실기.** 기기에 올려 손으로 만져 본 것이 아니다.
  터치 조작·성능·화면 회전은 이 확인으로 답하지 못한다.
- 긴 회차 완주, 관문 보스, 저장 판 불일치 화면(옛 저장을 브라우저에 심어 보지 않았다).
- 여러 브라우저 비교(하나에서만 봤다).

## 제약

- 웹 내보내기에는 대상 폴더를 미리 만들어 둬야 한다(엔진이 만들어 주지 않는다).
- COOP/COEP 머리글이 없으면 뜨지 않는다. 정적 호스팅에 올릴 때 그 설정이 필요하다.
- wasm 이 39.5MB다(압축 전). 배포할 때는 미리 gzip 해 두는 쪽이 낫다.

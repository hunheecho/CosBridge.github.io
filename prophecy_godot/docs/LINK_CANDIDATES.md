# 연계 후보 — 보존만 (2026-09-09)

사용자가 **"후보로만 보존하라"**고 한 것들이다.
**데이터에도 코드에도 넣지 않았다.** 수치도 정하지 않았다. 이름과 한 줄 설명뿐이다.

여기 있는 것을 구현하려면 **먼저 사용자에게 물어야 한다.**

## 이번에 하지 말라고 한 셋

| 이름 | 한 줄 설명 |
|---|---|
| 빙괴 밀치기 | 얼어붙은 적을 돌풍으로 밀어 **다른 적**에 부딪히게 한다(적끼리 충돌 — 이번 ⑤의 장애물 충돌과 다른 것). |
| 불길 몰이 | 돌풍이 불씨 장판을 밀어 **화염 파도**로 만든다. |
| 최후의 장난 | 도깨비 인형이 파괴될 때 **반격**한다. |

## 함께 보류로 남은 것 (같은 지시에서 나왔다)

| 이름 | 한 줄 설명 |
|---|---|
| 룬 지뢰 연계 경직 | 지뢰 폭발(`mine_blast`)에 경직을 붙이는 안. `stagger.sources`에 넣지 않았다. |
| 무기별 강타 누적 | 주무기마다 강타를 쌓아 큰 한 방을 만드는 안. **폐기됐다**(사용자 지시). |
| 잔영 분신 '헛친 틈' | 분신의 발동 방식을 바꾸는 안. 현재 발동 방식·기존 증강을 그대로 둔다. |
| 수호 방울 반격 | 방울이 막은 뒤 되받아치는 안. 적용하지 않았다. |

## 결정 대기 중인 것 (구현과 별개)

| 이름 | 한 줄 설명 |
|---|---|
| 돌풍(E) 조준 규칙 | 이동 방향이 조준을 덮는 문제. 선택지 A~D가 `docs/FEEDBACK_2026-09-09.md` ①절에 정리돼 있다. **확정하지 않았다.** |
| 숙주 파열 방아쇠 축소 | '어떤 죽음이든' → '주무기 처치만'으로 좁힌 것. 2026-09-10 확정으로 **장비 기술 네 종의 직접 처치**가 더해졌다(파쇄와 같은 다섯 경로 이름). 되돌리려면 `eligibility.effects.plague_host_burst.allow`를 `["*"]`로. |
| 장비 기술의 파쇄·숙주 파열 | **2026-09-10 확정으로 열렸다** — 찰나 가르기·낙성 강하·받아치기·되짚는 궤적. 결정 관·유예의 시계는 닫힌 채다. 대기 목록에서 내린다. |
| ①④의 무리전 미완성 | 파쇄·표식 폭발이 무리전에서 한 번도 완성되지 않는다(`docs/STAGGER.md` 12절). 값이 아니라 '한 대상을 오래 붙잡는가'의 문제다. |

# 가정·시험값 근거 (Godot 첫 전투)

값은 모두 시험값이며 최종 밸런스가 아니다. 근거가 바뀌면 여기와 `data/first_fight.json`, `docs/RULES.md`를 같이 고친다. 표의 "사용자 시험값"은 사용자가 수치를 정한 것, 그 밖의 "시험값"은 구현자가 정한 것이다. 2026-09-07 사용자가 0.3.1 기본값 조합 전체를 직접 플레이하고 긍정 평가했다(`docs/DESIGN_DECISIONS.md` D33) — 조합의 비교 기준이지 개별 값의 승인은 아니다.

## 늑대 물기 (godot-0.3.0)
| 값 | 근거 |
|---|---|
| 사거리 44(중심~중심) | 몸 반지름 14+14=28에 16을 더한 값. 붙은 상대(28)에는 확실히 닿고, 검격 사거리 95(중심 기준 109)의 절반 이하라 검격 거리 전체를 덮지 않는다. 플레이어 이동 220/s로 0.15초 고정 동안 33 이동 → 고정 뒤 옆·뒤로 빠지면 빠져나갈 수 있는 크기 |
| 전방 각도 100° | 돌진 판정 폭(늑대 반지름 합)보다 넓지만 반원 미만: 정면에 있으면 맞고 옆으로 빠지면 안 맞는 크기. 0.15초에 33 이동하면 사거리 44에서 약 37°를 벗어난다 |
| 준비 0.35 = 추적 0.20 + 고정 0.15 | 사용자 시험값. 분할은 돌진(0.6+0.15)의 고정 시간과 같게 두어 '!' 뒤 반응 시간이 두 공격에서 같다 |
| 유효 구간 0.10초 | 12단계. 고정 뒤 늦게 들어온 플레이어도 맞도록 순간 판정이 아닌 짧은 구간. 한 번만 타격 |
| 빈틈 0.4 · 재사용 1.2(빈틈 포함) | 사용자 시험값. 실제 물기 간격 = 0.35 + 0.1 + 1.2 = 1.65초 |
| 초기 편차 0~0.6초 | 물기 재사용 대기의 절반 정도. 같은 묶음 3~4마리가 같은 단계에 물지 않게 하되 첫 접촉 뒤 0.6초 안에는 모두 시도 가능 |
| 피해 12 | 기존 늑대 공격 피해 유지(사용자 결정) |

## 늑대 돌진 (godot-0.3.0 변경분)
| 값 | 근거 |
|---|---|
| 재사용 8초(빈틈 0.9 포함) | 사용자 시험값. 물기 간격 1.65초의 약 5배 → "돌진은 훨씬 드물게" |
| 첫 돌진 2~5초 | 사용자 시험값. 등장 직후 묶음이 동시에 돌진하지 않게 |
| 돌진 최소 거리 70 | 시험값. 물기 사거리 44 바로 밖(44~70)의 늑대는 돌진(256 이동)보다 접근·물기가 자연스럽고, "돌진 대기 끝났다고 근접 상대에게 억지로 돌진" 방지 |
| 동시 돌진 2(비교 3) | 사용자 결정. 통로 예고가 화면을 덮지 않는 수 |

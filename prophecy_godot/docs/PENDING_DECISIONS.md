# 아직 결정되지 않은 것 — 현재 동작과 제안의 차이

작성 2026-09-10 · 기준 `4d77496`(v1.3.2)

여기 있는 넷 중 **3·4는 2026-09-10에 결정됐다**(결정 기록만 남긴다). 1·2는 **아직 정해지지 않았다.** 결정 전까지
**기존 보유분을 조용히 삭제하거나 다른 것으로 치환하지 않는다.**
지금 코드가 무엇을 하고 있는지와, 고르면 무엇이 달라지는지를 나란히 적는다.

이미 결정된 것은 여기 없다. 그것들은 각 갈래 문서와 커밋에 있다.

---

## 1. 폐기 장비를 이미 보유한 옛 회차의 이전 처리

폐기 장비: `reprisal_shield` 반격 방패 · `relay_shield` 연계 방패

**지금 동작(아무것도 안 한 상태)**

| 자리 | 지금 |
|---|---|
| 자료에 정의 | 남아 있다 |
| 제작 후보 | 빠진다 (`PCatalog.equipment_retired`) |
| 상점 진열 | 빠진다 |
| 도감 총계 | 활성 목록에서 계산하므로 분모에 안 들어간다. 이미 연 기록은 "폐기한 제작법" 줄로 따로 보인다 |
| 이미 가진 개체 | **그대로 쓰인다.** 착용·해제·판매 전부 된다 |
| 저장 복구 | 자료에 있으므로 `_drop_unknown_equipment` 에 걸리지 않는다 |

**정해야 할 것** — 이미 가진 사람에게 무엇을 해 줄 것인가.

| 안 | 내용 | 잃는 것 |
|---|---|---|
| A(지금) | 그대로 둔다 | 없음. 옛 회차와 새 회차의 장비 구성이 달라진다 |
| B | 판매가를 올려 자발적 교체를 유도 | 없음. 경제 값이 하나 늘어난다 |
| C | 같은 칸의 다른 장비로 교환권 지급 | 새 화면·저장 항목이 필요하다 |
| D | 회차 시작 시 자동 회수·환급 | **사람이 고른 장비가 말없이 사라진다.** 권하지 않는다 |

관련: 이 둘은 `upgrade` 표가 비어 있어 강화해도 아무 값도 안 올랐다.
그 **차단은 별도로 확정됐다**(효과 없는 유료 강화 수정). 차단은 삭제가 아니다.

## 2. 빈틈 포착·지속력을 이미 보유한 옛 회차의 이전 처리

**지금 동작**

| 자리 | 지금 |
|---|---|
| 자료에 정의 | 남아 있다 (`passives` 10종 중 2종) |
| 신규 획득 후보 | **빠진다** (`offer: false`, 레벨 0일 때만 건너뛴다) |
| 이미 가진 것 | **그대로 작동한다.** 빈틈 포착 ×2.000 · 지속력 ×1.200 실측 확인 |
| 레벨업 후보 | 이미 가진 것은 계속 올릴 수 있다 |
| 저장 왕복 | 새 패시브와 섞여도 오류 없음 |

**정해야 할 것** — `docs/PASSIVE_SWAP.md` 3절에 5안이 있다. 요약하면:

| 안 | 내용 | 잃는 것 |
|---|---|---|
| A(지금) | 그대로 둔다 | 없음. 옛/새 회차 구성이 달라진다 |
| B | 보유는 유지하되 레벨업 후보에서도 뺀다 | 슬롯 하나가 현재 레벨에 묶인다 |
| C | 같은 레벨로 자동 치환 | **"임의로 치환하지 마라"에 정면으로 걸린다.** 권하지 않는다 |
| D | 슬롯을 비우고 다음 레벨업에 재선택 제시 | 새 제시 종류·저장·화면 변경이 필요하다 |
| E | 회차 시작 시점의 패시브 표를 저장에 고정 | 표 판본이 계속 늘어난다 |

권고: 그대로 두려면 **A**, 옛 패시브를 완전히 없앨 거면 **D**.

## 3. 흡혈에 주무기 개조의 추가 타격을 어디까지 포함할지 — **2026-09-10 결정됨**

**사용자 확정**: 주무기 기본 공격과 **그 추가 공격**이 전부 적격이다 —
① 주무기 개조가 만든 추가 타격 · ② 공용 증강 **메아리·연사**가 반복한 **주무기** 공격 ·
③ 장비 **공성 망치머리**의 착탄점 추가 충격. 위 표의 안 B에 해당한다.

**들어간 것**: `data/growth.json` `growth.LIFESTEAL.eligible`에 `main_extra`를 넣었다.

**그러나 값으로 재 보니 `main_extra` 한 칸에 허용 목록 밖의 것 넷이 섞여 들어왔다**
(`tools/pass_probe.gd` B0 감사, 실제 전투를 굴려 센 전수):
Q/E 일반 수동 기술(`skill:strike`) · 공용 '정지된 칼날' 폭발(`common:stasis`) ·
보스 보상 '무기 공명' 폭발(`reward:resonance`) ·
**메아리·일제 공격이 반복한 보조무기 공격**(`weapon:orb` 등).
넷 다 사용자 불허 목록에 있다.

그래서 자격표에 `require_main_weapon: ["main_extra"]`를 두어 **그 경로에 한해
그 타격의 주인이 주무기인지 한 번 더 본다.** 출처 분류(`PSupport.cause_of`)는 고치지 않았다 —
고치면 파쇄·감전 후속·까마귀 표적·숙주 파열의 `main_extra` 자격까지 함께 좁아진다.
자세한 표와 값은 `docs/PASSIVE_SWAP.md` §흡혈.

**남은 미확정**: 출처 분류 자체를 고칠지(= `cause_of`가 보조무기의 메아리·연사를
`support_direct`로 돌리고, 주인이 없는 파생 피해를 `main_extra`가 아닌 이름으로 돌리는 것)는
**정하지 않았다.** 고치면 흡혈만이 아니라 파쇄·감전·까마귀·숙주가 함께 달라지므로 사용자 결정이 필요하다.

## 4. 흡혈에 회복 준비(`heal_mult`)를 적용할지 — **2026-09-10 결정됨**

**사용자 확정**: 적용한다(위 표의 안 B). 곱하는 자리는 `CombatState.apply_lifesteal` **한 곳뿐**이고,
다른 회복 경로(체력 구슬 `update_pickups` · 승리 회복 `PRun` · 응급 약낭 · 물약)와 칸이 겹치지 않는다.
값: 검·쌍검·창·망치 1.500 → 1.650, 활 0.750 → 0.825 (정확히 ×1.1이며 ×1.21이 아니다).

전투당 회복 상한은 사용자 확정대로 **두지 않았다.** 대신 최대 체력을 넘긴 몫은
버리고 비축하지 않는다는 것을 값으로 못박았다(`stats.lifesteal_over`).

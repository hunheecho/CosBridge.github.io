# 결정 기록 — 정해진 것과 아직 안 정해진 것

작성 2026-09-10 · 마지막 갱신 2026-09-10

이 문서는 처음에 "아직 결정되지 않은 넷"으로 시작했다. **넷 다 정해졌다.**
그 결정과 근거를 아래에 남긴다. 새로 생긴 미결정은 맨 아래에 따로 모은다.

---

## 정해진 것

### 1. 폐기 장비를 이미 보유한 옛 회차의 이전 처리 — **종료**

폐기 장비: `reprisal_shield` 반격 방패 · `relay_shield` 연계 방패

**결정(2026-09-10)**: **이전 처리를 하지 않는다.** 이번 대규모 패치 이전 회차 자체를 폐기하기로 했기 때문에
"이미 가진 사람에게 무엇을 해 줄 것인가"라는 물음이 사라졌다.

무엇이 따라오는가
- 옛 회차는 이어하기가 막히고 "대규모 업데이트로 새 회차를 시작해야 합니다"가 뜬다.
- **옛 저장 파일은 지우지 않는다.** 프로필·도전과제·처치 기록·설정도 그대로다.
- 새 회차에서는 이 둘이 제작·진열·도감 총계에 아예 안 나온다. 자료 정의는 남아 있어
  옛 저장을 읽어도 `_drop_unknown_equipment` 에 걸리지 않는다.
- 이 둘의 **효과 없는 강화는 따로 막았다**(견적·확정 양쪽). 차단은 삭제가 아니다 —
  이미 가진 개체는 착용·판매가 그대로 된다.

관련 파일: `docs/SAVE_VERSION.md` · `tests/save_version_tests.gd`

### 2. 빈틈 포착·지속력을 이미 보유한 옛 회차의 이전 처리 — **종료**

**결정(2026-09-10)**: 위와 같은 이유로 **이전 처리를 하지 않는다.**
`docs/PASSIVE_SWAP.md` 3절의 다섯 안(A~E)은 전부 "옛 회차를 이어간다"는 전제 위에 있었고,
그 전제가 없어졌다.

지금 동작: 두 패시브는 자료에 남아 있고 **신규 획득 후보에서만 빠진다**(`offer: false`).
새 회차에서는 애초에 뽑히지 않으므로 보유분이라는 것이 생기지 않는다.

### 3. 흡혈에 주무기 개조의 추가 타격을 어디까지 포함할지 — **확정**

**사용자 확정(2026-09-10)**: 주무기 기본 공격과 **그 추가 공격**이 전부 적격이다.

| 적격 | 비적격 |
|---|---|
| 주무기 기본 공격 | 보조무기 공격 · 분신 모방 |
| 주무기 개조의 추가 타격(교차 검격·잔류 검흔·분열 창날·충격파·여진·갈래 사격) | Q/E 일반 수동 기술 |
| 공용 증강 **메아리·연사**가 반복한 **주무기** 공격 | Q/E 장비 변환 기술 |
| 장비 **공성 망치머리**의 착탄점 추가 충격 | 화상·독·출혈 등 지속 피해 |
| | 감전 추가 피해와 그 복제 |
| | 파쇄·방전·불꽃 파열·숙주 파열 등 연계 폭발과 파편 |
| | 반사 피해와 장애물 공격 |

들어간 자리: `data/growth.json` `growth.LIFESTEAL.eligible = ["main_direct", "main_extra"]`.

**`main_extra` 한 칸에 허용 목록 밖의 것이 섞여 들어온다는 것을 값으로 확인했다.**
그래서 두 겹으로 막았다.

1. `require_main_weapon: ["main_extra"]` — 그 경로에 한해 **그 타격의 주인이 주무기인지** 한 번 더 본다.
   이것이 막는 것: 메아리·연사가 반복한 **보조무기** 공격.
   실측(전부 켠 판) `weapon:orb` 적중 318회 · 깎은 체력 5151.6 → **회복 0.000**.
2. 일반 수동 기술은 **고유 출처 이름**을 갖게 했다(`skill_strike` 등 여섯).
   더 이상 `main_extra` 로 떨어지지 않는다. 실측 `skill:strike` 적중 36회 · 깎은 체력 2520.0 → **회복 0.000**.

남은 자리는 아래 KD-14 로 적었다.

### 4. 흡혈에 회복 준비(`heal_mult`)를 적용할지 — **확정**

**사용자 확정(2026-09-10)**: 적용한다. 곱하는 자리는 `CombatState.apply_lifesteal` **한 곳뿐**이고,
다른 회복 경로(체력 구슬 · 승리 회복 · 응급 약낭 · 물약)와 칸이 겹치지 않는다.
값: 검·쌍검·창·망치 1.500 → 1.650, 활 0.750 → 0.825 (정확히 ×1.1이며 ×1.21이 아니다).

전투당 회복 상한·흡혈 재사용 시간·발동 횟수 제한은 확정대로 **두지 않았다.**
대신 최대 체력을 넘긴 몫은 버리고 비축하지 않는다는 것을 값으로 못박았다(`stats.lifesteal_over`).

### 5. 옛 고정 판매가표 — **확정(정리 완료)**

`shop.sellPrice`(35/30/30)는 2026-09-09부터 규칙에서 쓰이지 않았고 도구 하나만 읽고 있었다.
그 도구(`tools/craft_economy.gd`)를 승인된 계산으로 옮긴 뒤 표를 지웠다.
**새 밸런스 결정이 아니라 참조가 끊긴 표의 정리다.**

### 6. 공성 추가 충격의 밀어내기·경직 — **확정(추가하지 않음)**

별도의 밀어내기·일반 경직은 추가하지 않는다. 승인된 추가 충격과 파쇄·연계 경직 동작은 그대로 둔다.
현재 구현이 이미 그 상태다(본타만 밀어내기·경직을 준다).

### 7. 감전 후속·까마귀 표적에 일반 수동 기술 자격을 줄지 — **확정(제외)**

**사용자 확정(2026-09-10)**: **둘 다 제외한다.**
그전까지는 합의 문구에 근거가 없어 미결정으로 두었고, 그때도 결과는 불허였다.
확정이 온 뒤로는 `data/supports.json` 의 `shock_bonus.deny` · `crow_mark.deny` 에
수동 기술 경로 여섯을 **명시**했다 — 결과가 같아도 "우연히 막혀 있다"와 "막기로 정했다"는
다른 사실이고, 나중에 분류가 바뀌어도 이 줄이 있으면 조용히 열리지 않는다.

툴팁도 그렇게 적었다:
- 번개 구체: "감전된 적을 주무기 또는 주무기의 추가 공격으로 타격하면 감전 추가 피해가 발생합니다.
  일반 Q/E 기술로는 발동하지 않습니다."
- 추격 까마귀: "주무기 또는 주무기의 추가 공격으로 맞힌 적을 공격 대상으로 지정합니다.
  일반 Q/E 기술은 까마귀의 표적을 바꾸지 않습니다."

## 아직 정해지지 않은 것

### KD-14 — '정지된 칼날'·'무기 공명' 폭발이 아직 `main_extra` 로 분류된다

공용 증강 **정지된 칼날**(`common:stasis`)과 보스 보상 **무기 공명**(`reward:resonance`)의 폭발이
무기 주인이 없는 파생 피해라 여전히 `main_extra` 로 떨어진다.

| 효과 | 지금 | 왜 |
|---|---|---|
| 흡혈 | 막힌다 | `require_main_weapon` 이 주인을 본다. 실측 회복 0.000 |
| 숙주 파열 | 막힌다 | `PSupportB._death_cause` 의 `zone_tick` 교정 |
| **파쇄** | **터진다** | 막는 것이 없다. 실측 `frost_cause_of = main_extra` · 자격 true · 파쇄 1회 · 빙결 해제 |

수동 기술 교정은 "일반 수동 기술"에 한정된 지시였으므로 이 둘은 **고치지 않고 보고만 한다.**
고치면 파쇄 밸런스가 바뀌므로 사용자 확정이 먼저 필요하다.

실측값: `common:stasis` 적중 72 · 깎은 체력 2710.0 / `reward:resonance` 적중 433 · 깎은 체력 17320.0
(둘 다 흡혈 회복 0.000).

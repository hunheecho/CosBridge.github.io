# 장비·상점·대장간 확장과 수동 스킬 창고 — 접수한 지시 (2026-09-09)

**상태: 큐에 있음. 진행 중인 '플레이 피드백 통합 수정(20절)'을 끝낸 뒤에 시작한다.**
사용자 지시 그대로: "다하고 이거 해."

이 문서는 **요구를 잃지 않기 위한 정본**이다. 이전 제안과 충돌하면 **이 문서가 우선**한다.
여기 적힌 수치는 **첫 시험값**이며 사용자 확정값이 아니다(구분해서 보고할 것).

## 0. 시작 전에 할 일 (사용자 지시)

> "기존 작업을 먼저 확인하고, 아래 내용을 **이미 구현된 것 / 수정할 것 / 새로 구현할 것**으로
> 구분한 뒤 진행하세요."

### 착수 시점에 확인한 사실 (2026-09-09)

**장비는 지금 '개체'가 아니다.** `run.equipment = { weapon: null, armor: null, shield: null }` 와
`run.bag = []` 가 **문자열 id만** 담는다(`scripts/rules/run.gd:42`).
저장·복구도 그 문자열을 그대로 옮긴다(`run.gd:1554`, `1598`).

→ 그런데 4절이 요구하는 것은 **강화 단계가 그 장비 개체에 귀속**되고
  **"동일 종류를 여러 개 보유해도 각각의 장비 상태를 구분"** 하는 것이다.
→ 즉 **장비를 id 문자열에서 개체(dict)로 바꾸는 저장 구조 변경**이 필요하다.
  옛 저장(문자열)을 읽어 개체로 올리는 변환과, 그 변환이 금화·최대 체력·판매가·제작·
  대장간 표시 어디에도 구멍을 내지 않는지가 이 작업의 **가장 큰 위험**이다.
  (사용자 지시: "사용자 원본 저장은 수정하거나 덮어쓰지 않는다.")

## 1. 장비 범위와 폐기

**유지 — 일반 12개**
무기: 사냥꾼의 검 · 개척자의 창 · 잔불검 · 시간술사의 지팡이
갑옷: 여행자의 경갑 · 수호자의 갑옷 · 생명력의 외투 · 원정대의 갑옷
방패: 철벽 방패 · 비상 방패 · 시전자의 방패 · 시간의 방패

**유지 — 제작 4개**: 혈월검 · 잔향의 지팡이 · 재생의 여행복 · 월광 갑옷

**폐기 — 제작 2개**
- 반격 방패(큰 타격을 버티면 Q/E 재사용 감소)
- 연계 방패(Q 이후 E 사용 시 보호막)

> 폐기 장비는 신규 **상점·제작·보상 후보에서 제거**한다.
> **기존 저장에 든 것을 아무 보상 없이 삭제하지 말고**, 보유·장착·제작 진행 상태를 조사해
> **이전 처리안을 제시**한다(임의 확정 금지).
> **주의: 폐기하는 '반격 방패'와 신규 '받아치기'는 다른 것이다.** 이름·자료 ID를 혼동하지 말 것.

**총 기획 범위 = 유지 16 + 신규 10 = 26.** 구현 완료 개수가 아니다.
> 초기 제안의 '일반 24 + 제작 12'를 맞추려고 비슷한 장비를 억지로 추가하지 않는다.
> 신규 10개의 **일반/제작 구분과 착용 부위는 역할에 맞춰 배정하고 배정표를 보고**한다.
> **장비 슬롯 자체를 추가하지 않는다.**

## 2. 장비의 기본 구조

기본 능력치 **하나** + 장비 고유 효과.
- 기본 능력치 = 구매 직후의 안정적인 이득. 고유 효과 = 그 장비를 고르는 핵심 이유.
- 한 장비에 **작은 능력치를 여러 개 나열하지 않는다.**
- 모든 장비에 억지로 "이득 +20% / 다른 것 −20%"를 붙이지 않는다.
- **단순 능력치 장비도 남긴다.** 강한 고유 효과 장비가 기본 능력치까지 항상 최고여선 안 된다.
- 예: 공격 장비 = 공격 능력치 + 공격/연계 변화 · 갑옷 = 최대 체력 또는 이동속도 + 생존/행동 변화
  · 방패 = 보호막 또는 방어 능력치 + 방어 행동.
- **기존 능력치 체계로 되는 것은 그 체계를 쓴다. 새 능력치 체계를 만들지 않는다.**
- 부위와 기본 능력치 값은 **미확정** → 현재 경제·기존 장비와 비교한 **첫 시험값**으로 정하고
  사용자 확정값과 **구분해 보고**.

## 3. 신규 장비 10개 (이름은 가칭, 핵심 동작은 확정)

### [1] 공성 망치머리
- 전투망치 최초 착탄 후 **전방으로 균열**이 뻗고 추가 충격.
- 최초 착탄에 맞은 적도 **추가 충격에 다시 맞을 수 있다.**
- 추가 충격 피해 = **최초 타격의 50%**.
- 한 추가 충격에 **같은 적이 여러 번 맞지 않는다.**
- 계산 기준은 **최초 타격의 공격 피해**로 명확히. **실제로 잃은 체력이나 과잉 피해를
  다시 피해량으로 쓰지 않는다.**
- **망치가 없으면 작동하지 않는다는 것을 장비 설명과 상점에 표시.**

### [2] 감전 추가 발동 장비
- 방향: 감전 효과가 한 번 더 발생.
- 구체화: **일반 감전 추가 피해를 같은 적에게 한 번 복제.**
- **큰 방전 폭발까지 복제하는 것은 미확정.** 일반 감전과 방전을 같은 이름으로 뭉뚱그리지 말 것.
- **추가로 생긴 피해가 자기 자신을 다시 호출하면 안 된다.**
- **복제 피해가 방전 충전 등 다른 연계의 횟수에 포함되는지 명시적으로 정리**하고,
  기존 효과로 위장시켜 우연히 연결하지 않는다.
- 번개 구체의 기본 성능 문제는 별개. **이 장비를 이유로 구체 기본 성능을 임의로 낮추지 않는다.**

### [3] 빙결 요구량 감소 장비
- 빙결에 필요한 냉기 중첩 수를 줄인다. **5 → 4는 첫 시험값.**
- **기존 재빙결 제한 유지.** 보스의 결빙과 일반 적의 행동 정지를 구분.
- **장비 강화로 요구량을 계속 깎아 무한 빙결에 접근시키지 않는다.**

### [4] 찰나 가르기 (Q/E 배치 장비 기술) — '벽력일섬' 명칭 사용 금지
- 누르는 동안 **제자리에서 짧게 충전**하며 방향 선택. **발동 직전에 방향 확정.**
- 놓으면 전방을 일자로 베며 **순간 이동**. 경로의 적을 **한 번씩** 공격, 적 몸은 관통.
- **벽·바위·나무는 통과하지 않고 장애물 앞 유효한 위치에서 멈춘다.**
- 충전 중에는 **공격받을 수 있다.** **발동하는 짧은 순간에만 무적.**
- **충전 중 Space로 취소 가능.**
- **큰 적이라는 이유로 같은 발동에 여러 번 맞지 않는다.**

### [5] 낙성 강하 (Q/E 배치 장비 기술)
- 누르는 동안 착지점 선택, 놓으면 도약해 내려찍기.
- 착지 중심 = 강한 타격, 바깥 = 약한 충격파.
- **발동 뒤 착지점을 계속 추적해 바꾸지 않는다.**
- **유효하지 않은 지형에 착지하지 않는다.**
- **도약 중 피격·무적 범위는 별도 시험값으로 명시.**
  **'공중'이라는 이유로 기존 코드가 무적을 암묵적으로 부여하게 두지 않는다.**

### [6] 받아치기 (Q/E 배치 장비 기술)
- 짧게 정면 방어. **한 번 막으면 강한 부채꼴 반격.** 못 막으면 약한 방패 밀치기로 끝.
- **오래 눌러도 지속 방어하지 않는다.**
- **정면 직접 타격과 투사체**에 대응. **장판·지속 피해는 막지 않는다.**
- **같은 공격 한 번으로 반격이 중복 발생하지 않는다.**
- 폐기 대상 '반격 방패'와 **이름·자료 ID 혼동 금지.**

### [7] 되짚는 궤적 (Q/E 배치 장비 기술)
- 첫 입력: 현재 위치 표시 + 이후 이동 경로를 짧게 기록.
- 재입력: 기록한 길을 **빠르게 거슬러 돌아오며** 경로의 적을 공격.
- **적 하나는 귀환 한 번당 한 번만** 맞는다. 같은 적 주변을 여러 번 돌아도 중복 누적 없음.
- **기록 시간·길이는 유한.**
- **기록 후 지형이 달라져도 벽을 뚫거나 유효하지 않은 위치로 가지 않는다.**
- **기록 만료·화면 전환·전투 종료 시 처리와 재사용 시간 기준을 명시.**

### [8] 결정 관 (Q/E 배치 장비 기술)
- 누르는 동안 **짧게 얼음에 갇혀 피해를 막는다.** 그동안 이동·공격 중단.
- **보조무기도 그동안 새 공격을 시작하지 않는다.**
- 놓으면 해제되며 **주변 적에게 냉기 부여.** **최대 유지 시간 유한.**
- **이미 발사한 투사체·설치된 장판과 '새 공격의 중단'을 구분.**
- **버튼 취소/앱 전환/회전 때문에 무적 상태가 남으면 안 된다.**

### [9] 유예의 시계 (Q/E 배치 장비 기술)
- 짧은 시간 동안 받은 피해 일부/전부를 즉시 차감하지 않고 **'예정된 피해'로 표시.**
- 효과가 끝나면 남은 예정 피해를 정산.
- **효과 중 주무기로 실제 피해를 주면 예정 피해 일부를 지울 수 있다.**
- **보조무기·지속 피해만으로 예정 피해가 자동으로 전부 지워지지 않는다.**
- 미루는 비율·상한·지우는 양·정산 시간은 **미확정 시험값.**
- **방어·보호막·무적 처리 순서를 명확히 정의.** 이미 막힌 피해를 예정 피해로 잡거나
  방어 효과를 두 번 적용하지 않는다.
- **재사용·장비 해제·전투 종료로 예정 피해가 조용히 삭제되는 구멍을 막는다.**

### [10] 잔영 허물 (Space 자체를 변형하는 장비)
- 회피 출발점에 짧게 잔영을 남긴다. **아직 조준 중인 적은 잠시 잔영을 겨눈다.**
- **이미 확정된 공격 방향이나 실행 중인 공격은 바꾸지 않는다.**
- 잔영은 **공격 한 번을 받으면 사라진다.**
- **광역 공격의 실제 피해 영역을 지우거나 대신 모두 받아주지 않는다.**
- **보스의 강제 위치 이동·영구 유인 수단으로 쓰지 않는다.**
- **무기별 Space 재사용 시간·거리·무적 시간을 임의로 늘리지 않는다.**
- 도깨비 인형의 지속 유인과 구분되는 **'회피 순간 조준 교란'**이다.

## 4. 장비 강화 (이전 제안 정정)

**+0 → +1 → +2 두 단계.** +1은 첫 관문 돌파 후, +2는 두 번째 관문 돌파 후.
금화 소비 · 확정 성공 · **시간 소모 없음.** 비용·상승량은 경제 기준 **시험값.**

**핵심: 강화 단계는 '강화한 그 장비'에 귀속된다.**
- 다른 장비로 **강화 이전 금지.**
- 가방에 넣어도 **그 장비의 강화는 유지.**
- 다른 장비를 착용했다고 **새 장비에 강화가 따라가면 안 된다.**
- **동일 종류를 여러 개 보유해도 각각의 장비 상태를 구분.** ← 0절의 저장 구조 변경이 필요한 이유

고유 효과는 **+0부터 완성된 동작**을 제공한다. 기본 강화는 **기본 능력치만** 올린다.
**강화에 따라 자동으로 올리지 않을 것**: 추가 충격 횟수 · 감전 복제 횟수 ·
빙결 요구량 감소 단계 · 장비 기술 레벨 · 무적 시간.

**제작 시 강화 자동 계승은 승인되지 않았다.** 기존 제작 처리와 강화된 재료 장비 사용 문제를
**조사하고 처리안을 제시**한다. **강화 이전·자동 계승을 몰래 추가하지 않는다.**
이 미결정 때문에 **다른 확정 작업까지 중단하지 않는다.**

**기존 자동기술 강화 기능과 새 장비 강화를 같은 것으로 취급하지 않는다.**
기존 기능의 제거·가격 변경은 이번에 자동 승인된 것이 아니다.
**화면에서 무엇을 강화하는지 분명히 구분한다.**

## 5. 일반 수동 스킬과 장비 기술의 분리

**'Q Lv3이면 변환 기술도 Lv3' 제안은 폐기.**

**일반 수동 스킬**: 스킬 자체가 레벨과 개조를 가진다. **Q/E에서 빼도 소유권·레벨·개조를
잃지 않는다.** 스킬 창고에 보관하고 다시 꺼내 쓴다.

**장비 기술**: 그 장비를 착용해서 쓰는 별도 기술. **레벨업 불가.** 정해진 성능.
- 기존 Q/E의 레벨·개조를 **계승하지 않는다.** 장비 강화로 기술 레벨이 오르지 않는다.
- **일반 스킬 레벨업·개조 보상 후보로 잘못 등장하지 않는다.**
- UI에 **'Lv1/3' 같은 성장 가능 표시를 붙이지 않는다.** '장비 기술 · 성장 없음' 등으로 명확히.

**장비 기술의 경쟁 비용**: 장비 한 칸을 차지 · 레벨업/개조 불가 · 기존 기술 하나 대신 Q 또는 E 사용.
이 비용이 있으므로 **억지로 별도 벌점을 붙이지 않는다.** 상위호환으로 만들지도 않는다.

**'고정 성능'은 '레벨업 불가'라는 뜻이다.** 다른 전투 효과와의 상호작용까지 전부 무시한다는
뜻이 아니다. **피해 증가·상태이상·연계 자격은 출처별로 명확하게 정한다.**

## 6. 스킬 창고와 Q/E 편성

거점에서 **시간·금화 소모 없이**: 보유 일반 스킬을 Q/E에 넣기 · Q/E의 일반 스킬을 창고로 빼기 ·
**Q와 E를 한 번에 맞바꾸기** · 착용 장비가 주는 기술을 Q/E에 배치.

- **같은 기술을 Q와 E에 중복 배치하지 않는다.** 장비 기술도 슬롯 제한을 우회하지 않는다.
- **전투 중 자유 교체로 재사용 시간을 우회하는 기능은 추가하지 않는다.**

예: Q 감속장 Lv3 / E 낙뢰 Lv2 → 찰나 가르기 착용 → Q에 배치 →
**감속장 Lv3과 개조는 창고에 그대로 보관** → 장비를 벗으면 찰나 가르기 사용 불가 →
빈 Q에 감속장 Lv3 또는 다른 보유 기술을 **직접 선택해** 넣음.

- **장비를 벗었다고 보관 스킬을 삭제하거나 임의의 일반 스킬을 자동 선택하지 않는다.**
- **장비 착용으로 '사용 가능'해지는 것과 Q/E에 '배치'하는 것을 구분한다.**
- Q/E 위치를 바꾸면 레벨·개조·고유 상태는 **그 기술을 따라간다.**
  **재사용 시간을 초기화하거나 짧은 쪽으로 바꾸는 구멍이 없어야 한다.**
  키 표시·모바일 버튼·설명·효과 발동이 **모두 새 배치와 일치.**
- **기존 '새 수동 스킬 획득/교체' 경로를 전부 점검.** 창고를 추가했는데 예전 교체 코드가
  보유 스킬을 삭제하면 안 된다. 기존 보상·상점 획득 흐름과 편성을 연결한다.

## 7. 스킬별 증강·기존 장비와의 관계

**보유 / 창고 보관 / Q·E 배치 / 장비 착용** 상태를 구분한다.
- **창고에 있는 감속장 때문에 감속장이 사용 중인 것처럼 전투 효과가 발동하면 안 된다.**
- **'Q 슬롯 조건'과 '감속장 사용' 같은 기술 조건을 구분.** 감속장이 **E에 있어도** 관련 효과는 동작.
- 장비 기술로 슬롯을 바꿨다면 **원래 기술 전용 개조는 보관되며 새 장비 기술에 적용하지 않는다.**
- 일반 스킬을 다시 배치하면 **보관된 레벨·개조가 복구된다.**
- 시간술사의 지팡이 · 시간의 방패 · 잔향의 지팡이 · 월광 갑옷 등은 **감속장 미사용 시
  효과가 비활성임을 보여준다.** Q/E 변경만으로 이 장비들을 **조용히 삭제하지 않는다.**

**장비 기술이 기존 연계를 부를 자격을 명시적으로 작성한다.**
외형이 검격이라고 모든 피해를 `main_direct`로 처리하지 않는다. 특히:
파쇄를 깨는가 · 감전 후속을 부르는가 · 방전 충전에 포함되는가 ·
까마귀 표적에 영향을 주는가 · 숙주 파열의 처치 자격인가.
**바로 결정되지 않는 항목은 별도 제안으로 보고.** 승인되지 않은 연쇄를 우연히 열거나,
안전하다는 이유로 **모든 시너지를 일괄 차단하지 않는다.**

모바일 스크롤 중 오입력 / 닫기·취소·뒤로·계속이 실제로 작동하지 않음 /

**재현하지 못한 증상을 다른 결함 하나 고친 것으로 해결 처리하지 않는다.**

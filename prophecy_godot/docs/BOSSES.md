# 관문 보스 9종 — 신규 6종 정본 (godot-0.5.x, 2026-09-07)

이 문서가 신규 보스 6종의 **정본**이다(패턴·예고 시간·단계 규칙·시험값·필수 판정 상태·봇 검증 범위). 기존 3종(가시갈기 `boss`·봉인 수호자 `guardian`·예언을 먹는 자 `eater`)은 `../../docs/CONTENT_MATRIX.md` F절 그대로이며 이 작업에서 수치·행동을 바꾸지 않았다.
근거: 계획 문서 §7 "보스 9종의 차별화"(공통 규칙·패턴 표·신규 보스별 필수 판정)·§12(검증). **모든 숫자는 시험값(사람 승인 아님)**이며 `data/bosses_new.json`에만 있다(`enemies.json`·`config.json`은 손대지 않고 `PCatalog.boss_defs()/boss_def()/boss_hp_sets()/boss_action_text()/enemies()`가 합친다).

코드: `scripts/rules/boss3.gd`(`PBoss3`: init/choose/begin/update/threats/in_danger/shield_mult/summon), 연결 훅 `boss2.gd`(init/update/is_committed/in_danger/threats 5줄) · `enemies.gd`(shield_mult 1줄) · `combat_state.gd`(update_player 빙판 2줄), 그리기 `scripts/game/render.gd`(`draw_boss` 분기 + 보스별 실루엣 6 + `draw_boss3_telegraphs` + 지역 `ice`/`rubble` + 효과 `slashline` + 투사체 `boss_bolt`/`boss_icebolt`), 테스트 `tests/boss3_tests.gd`(111), 시뮬 `tools/boss_sim.gd`(9종, 막별 관문 빌드).

## 행동 개편 — 연계(chain)·옆 뛰기(hop) (2026-09-08, 사용자 요청 §6, 보스 9종 공통)

사용자 피드백 "보스가 너무 가끔 공격한다 / 붙어 있는 것이 안전하다 / 분당 공격 개시를 최소 2.5배로 시험해 달라"에 대한 **행동** 변경이다.
**체력(HP)은 이 작업에서 손대지 않았다**(다른 작업이 `data/enemies.json`에서 정한다). 새 수치는 전부 `data/boss_behavior.json`에 있고 **모두 시험값(사람 승인 아님)**이다.
`enabled: false`로 두면 개편 전(073f74f) 행동으로 완전히 돌아간다. 개체 단위로는 `e.beh_off = true`(단위 시험용).

코드: `scripts/rules/boss.gd`의 공통 엔진(`chain_*` / `hop_*` / `prep_speed` / `pat_num`)을 `boss2.gd`·`boss3.gd`가 같이 쓴다.
계측: `tests/boss_pace_tests.gd`(고정 조건 빈도·예고·빈틈), `tools/boss_sim.gd`(정책·Q·개편 on/off 대조군), 보고서 `docs/sim/BOSS_PACE.md`.

| 바꾼 것 | 내용 | 안 바꾼 것 |
|---|---|---|
| 연계(chain) | 한 행동이 끝나면 빈틈 대신 짧은 이동 구간(linkGap 0.04초)만 두고 다음 행동으로 잇는다. 단계별 최대 6/8/10회. 연계가 끝난 시점에만 빈틈이 오고, 3회 이상 이어졌으면 +0.2초 더 길다 | 빈틈 자체의 길이(패턴별 recover 값), 빈틈 피해 ×1.5 |
| 후속타 예고 | 연계 2번째부터 예고 진행이 ×2.4로 빨라지되 **0.45초 하한**을 넘지 않는다 | **연계 첫 공격의 예고는 데이터 원래 값 그대로**(1.05~1.7초). 모든 예고를 같은 비율로 줄이지 않았다 |
| 행동 사이 대기 | `minApproach` 0.4~0.5 → 0.08초(예고가 아니라 아무것도 안 하는 시간) | 예고·확정·실행 시간 |
| 옆 뛰기(hop) | 최소 거리를 못 채운 돌진·돌파·사격을 고르면, 준비 구간 안에서 예고 없이 옆(+약간 뒤)으로 뛰어 스스로 거리를 만든다. 몸은 그대로 맞는다(무적 없음) 
 대상: 가시갈기 돌진 · 파수장 돌파/석궁 · 거수 굴착 · 추적자 얼음 발사/돌진 · 사냥왕 돌진 | 실제 사거리·판정 반지름, 예고 도형 |
| 착탄 대기 단축 | 표식·포자 탄·낙석은 정해진 시각에 스스로 터지므로(`update_marks`/`update_rocks`), 보스가 그 앞에서 서서 기다리지 않고 `chainAfter` 뒤 다음 행동으로 잇는다 | 착탄 시각·순서·위치 예고(감속장 무관 규칙도 그대로) |
| 소환 뒤 | 늑대·호위를 부른 직후 보스가 바로 공격으로 잇는다(소환이 주공격을 대신하지 않는다). 이을 것이 없으면 0.9초 빈틈으로 끝난다 | 소환 상한·간격·예산 |

규칙 안전장치:
- **연계는 보스가 approach에서 스스로 고른 행동에서만 이어진다**(`chain_arm`/`chain_live`). 규칙 밖에서 상태를 직접 넣은 행동(시험·디버그)은 개편 전처럼 한 번 치고 빈틈으로 간다.
- 단계 전환(roar)·방벽 파열(stagger)은 연계를 끊는다.
- 같은 행동 3연속 금지(`PBoss._pick_weighted`)는 연계 안에서도 그대로다.
- **감속장(Q)은 조용히 약화하지 않았다**: 예고 배속은 `adv = dt × time_factor × warn_speed`에서 `warn_speed`만 건드리므로 Q의 ×0.4는 준비·이동·실행·빈틈 전부에 그대로 곱해진다. 대신 빈틈이 "행동마다 한 번"에서 "연계마다 한 번"으로 바뀌어, Q로 늘어난 빈틈이 분당 몇 번 오는지가 줄었다(보고서 §Q 비교).

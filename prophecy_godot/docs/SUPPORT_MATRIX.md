# 보조 12종 · 개조 36개 — 역할과 실제 연결표

2026-09-09. **여기 있는 수치는 전부 시험값이다.** 사람이 승인한 밸런스가 아니고, 봇 계측으로 재미가 승인된 것도 아니다.

- 규칙 코드(`scripts/**`)와 `data/**`는 **읽기만 했다.** 결함은 고치지 않고 6절에 재현·기대·실제·근거로 적는다.
- 근거로 쓴 측정: `docs/sim/SYNERGY_PROBE.md` · `docs/sim/BUILD_PROBE.md` · `docs/sim/SPREAD_PROBE.md` · `docs/sim/SUPPORT_SCENE.md`
- 이어지는 시너지 검수는 `docs/SYNERGY.md`, 전염 상한 비교는 `docs/sim/SPREAD_PROBE.md`

## 0. 읽는 법

### 0-1. '개별 구현 완료'와 '시너지 완성'은 다르다

| | 상태 |
|---|---|
| 보조 12종 · 개조 36개의 **개별 구현** | **완료**(`impl: true` 12/12 · 36/36. 4절에서 개조마다 실제 코드 줄을 짚었다) |
| **시너지(효과끼리의 연결)** | **완료가 아니다.** 상태를 공급하는 보조는 많은데 **그 상태를 받아 추가 효과를 일으키는 쪽이 거의 없다**(5절) |
| 시너지 **밸런스** | 손대지 않았다 |

### 0-2. 상태 넷의 뜻

| 상태 | 뜻 |
|---|---|
| **실제 연결됨** | 코드가 있고, 실제 전투 경로에서 도는 것을 측정으로 확인했다 |
| **구현 누락** | 설명·자료에는 있는데 코드가 그것을 읽지 않는다 |
| **설계만 있음** | 자료(`data/**`)나 문서에만 있고 부르는 쪽이 없다 |
| **효과가 약하거나 잘 안 보임** | 코드도 돌고 측정도 되지만 크기가 작아 플레이에서 알아채기 어렵다 |

### 0-3. 판단할 때 지킨 것(사용자 지시)

1. **같은 상태이상을 여러 보조가 준다는 이유만으로 '중복'이라 부르지 않았다.** 감전·둔화·독을
   여러 경로로 공급하는 것 자체가 조합의 일부다. 여기서 문제로 적은 것은 **공급이 겹치는 것**이 아니라
   **공급을 받아 주는 쪽이 없는 것**이다(5절).
2. 목표는 "증강을 골랐을 때 **공격 방식·위치 선정·적 처리 순서가 달라지고 강한 연쇄가 눈에 보이는 것**"이다.
   **단순 피해 몇 퍼센트 증가로만 갈린 개조는 그렇다고 적었다**(3절).
3. **계측이 연결되지 않은 값은 0으로 적지 않고 '미계측'으로 적었다.** 무엇이 미계측인지는 7절에 모았다.

## 2. 보조마다 — ① 무엇을 보완하는가 ② 개조 셋이 서로 다른가 ③ 공급 → 소비 사슬

### ① 회전 칼날 (`blades`, `weapons.gd:539` `update_orbit`)

1. **보완**: 플레이어 주위 반지름 78을 상시 벤다. **추적궁·관통창**처럼 붙은 적을 처리할 수단이 없는 주무기의
   최근접 구멍을 메운다. 쌍검에게는 이미 있는 것을 더해 주는 쪽에 가깝다.
2. **개조 셋**: 칼날 +1(`dual`) · 사출(`launch`) · 톱날(`serrated`).
   **셋 다 "더 많이 때린다"의 변주다.** 위치 선정·표적 선택·처리 순서가 달라지는 것이 하나도 없다 →
   **사실상 같은 선택에 가깝다**(3절에서 셋 모두 '수치만 바꾼다').
3. **사슬**: 접촉 피해가 `cause: "orbit"` → 자격표 어휘 `support_direct`(`support_weapons.gd:57`).
   그래서 **감전된 적을 칼날이 스치면 감전 후속이 터진다**(측정 확인). 톱날은 출혈을 공급하고,
   출혈은 `PGrowth.has_bleed_source`로 장비·희귀 보상의 자격을 연다.
4. **상태**: 실제 연결됨.

### ② 번개 구체 (`orb`, `weapons.gd:362` `fire_chain`)

1. **보완**: 특정 주무기를 위한 것이 아니라 **모든 주무기의 화력을 한 단계 올리는 상태 공급원**이다.
   감전 후속은 주무기 직접·주무기 개조 추가·보조 직접·분신 모방 넷에서 다 터진다.
2. **개조 셋**: 분기(`fork`) · 순환(`loop`) · 축전(`conduct`).
   분기와 순환은 **같은 축**(연쇄를 더 많이/한 번 더)이다. 축전만 성격이 다르다 —
   감전 후속 3회를 모으면 반경 96에 방전하므로 **적을 모아 두는 것이 이득**이 된다.
3. **사슬(이 게임에서 가장 잘 이어진 곳)**:
   `기본 연쇄가 감전을 건다`(`weapons.gd:374`) → `감전된 적을 직접 계열로 때린다`(`weapons.gd:723`)
   → `추가 번개 40% · 반경 50` → (축전이면) `3회마다 방전 60% · 반경 96`.
   **방전은 감전을 다시 걸지 않는다**(`no_conduct`) — 자기 호출 금지.
4. **상태**: 실제 연결됨.

### ③ 서리 수정 (`frost`, `weapons.gd:420` `fire_bolt`)

1. **보완**: 냉기는 이동 속도를 0.6배로 만든다(`combat_state.gd:411`).
   **쌍검**(붙어 있어야 3연타가 다 들어간다)과 **전투망치**(예고 0.45초 뒤 그 자리를 친다)가 가장 크게 덕을 본다 —
   적이 걸어 나가지 못하면 두 무기의 약점이 그대로 사라진다.
2. **개조 셋**: 부채(`fan`) · 파편(`shatter`) · 차가운 바닥(`ground`).
   부채와 파편은 **같은 축**(더 많이 맞힌다). 차가운 바닥만 다르다 — 바닥에 2초짜리 둔화 지대가 남아
   **그 위에서 싸울 이유**가 생긴다.
3. **사슬 — 여기가 문제다**: 냉기를 **공급**하는 곳은 넷이다(서리 탄환 · 차가운 바닥 · 서리 함정(지뢰) · 공용 증강 '서리').
   그런데 냉기를 **받아 추가 효과를 내는 곳**은 **공용 증강 '서리'의 처치 시 얼음 파편 하나뿐**이다
   (`combat_state.gd:1554`). 보조 12종 중 냉기를 소비하는 것은 **하나도 없다.**
   즉 서리 수정을 골라도 다른 보조와 이어지지 않고 "적이 느려진다"에서 끝난다.
4. **상태**: **효과가 약하거나 잘 안 보임**(둔화 자체는 작동한다. 이어지는 곳이 없다).

### ④ 불씨 정령 (`ember`, `weapons.gd:435` `fire_ember`)

1. **보완**: 적이 걸어 들어오는 길에 불길을 깐다. **추적궁·관통창**처럼 거리를 두고 싸우는 주무기가
   "다가오는 시간" 자체를 피해로 바꾼다.
2. **개조 셋**: 산개(`scatter`) · 화염 띠(`trail`) · 재점화(`reignite`).
   산개와 화염 띠는 **같은 축**(불길을 어떤 모양으로 까는가, 둘 다 자동 배치). 재점화만 다르다 —
   **불길 위에서 처치하면 그 불길이 1.5초 늘어난다**(상한 +4.5) → 적을 어디로 몰아 죽일지가 달라진다.
3. **사슬(사용자가 유일하게 만족한 효과의 자리)**:
   `불길 장판` → `그 위에서 적을 처치` → **공용 증강 '불꽃 파열'**(`combat_state.gd:1561`)
   → 반경 폭발 → 그 폭발이 다른 적을 죽이면 또 터진다. 측정: **한 마리 처치 → 연쇄 처치 9**.
   **다만 소비자가 보조가 아니라 공용 증강이다.** 불길을 받아 주는 보조는 없다.
4. **상태**: 실제 연결됨(연쇄 크기의 기준점).

### ⑤ 룬 지뢰 (`mine`, `weapons.gd:460`·`weapons.gd:613`)

1. **보완**: 플레이어 발밑에 깔린다. **추적궁**처럼 물러나며 싸우는 주무기가 지나온 길을 함정으로 남긴다.
   검·쌍검처럼 앞으로 파고드는 무기와는 방향이 반대다.
2. **개조 셋**: 연결 폭발(`chain`) · 서리 함정(`frosttrap`) · 유인 룬(`lure`). **셋이 서로 잘 갈렸다.**
   연결 폭발은 지뢰를 **뭉쳐 깔 이유**를, 유인 룬은 **적이 지뢰로 걸어오게** 만들고, 서리 함정만 상태 공급이다.
3. **사슬**: 폭발이 `cause: "mine"` → `mine_blast`(`weapons.gd:623`). 자격표가 감전 후속을 막으므로
   **지뢰 폭발로는 감전이 터지지 않는다**(확인). 서리 함정은 냉기를 공급하지만 ③과 같은 이유로 받는 쪽이 없다.
4. **상태**: 실제 연결됨. 관찰 하나는 6절 SM-2(유인 룬이 등급 저항을 거치지 않는다).

### ⑥ 추격 까마귀 (`crow`, `supports_a.gd:151`)

1. **보완**: **주무기가 직접 맞힌 적**을 3초 동안 물고 늘어진다. 본체가 다른 적을 상대해도 계속 쫀다.
   **관통창·추적궁**처럼 표적을 하나씩 고르는 주무기와 결이 같고, 쌍검처럼 이미 한 대상에 화력을 쏟는 무기와는 겹친다.
2. **개조 셋 — 12종 중 가장 잘 갈렸다.** 셋이 전부 **표적 정책**을 바꾼다.
   집중 사냥(`hunt`)은 "안 바꾸는 것이 이득"(단계당 +15%, 최대 +60%),
   먹잇감 전환(`switch`)은 "빨리 죽이고 갈아타는 것이 이득"(다음 첫 공격 200%),
   쌍둥이(`twin`)는 "두 마리를 동시에"(개체 65%).
   → **적 처리 순서가 개조마다 실제로 달라진다.**
3. **사슬**: `주무기 직접·개조 추가 타격` → `crow_mark` 자격(`supports_a.gd:780`) → 표적 지정 →
   까마귀의 쪼기가 `support_direct` → **감전 후속을 터뜨릴 수 있다.**
4. **상태**: 실제 연결됨.

### ⑦ 수호 방울 (`bell`, `supports_a.gd:318`)

1. **보완**: 날아오는 적 투사체를 대신 막는다. **쌍검·전투망치**처럼 붙어 있느라 화살을 피할 수 없는
   주무기의 약점을 정확히 겨눈다.
2. **개조 셋**: 겹울림(`layered`, 저장 +1 · 충전 30% 느림) · 근접 수호(`guard`, 근접 한 대 50% 경감) ·
   되돌림(`reflect`, 반격탄 12).
   **역할은 갈리지만 플레이는 갈리지 않는다** — 셋 다 전자동이라 플레이어가 "언제 쓸지"를 고르지 않는다.
   근접 수호는 투사체 차단과 **같은 충전**을 쓰는데, 무엇에 쓸지는 코드가 먼저 온 것에 쓴다(선택권이 없다).
3. **사슬**: `적 투사체` → `blockable` 목록(`data/supports.json` `bell.base.incoming`) → 차단 → (되돌림이면) 반격탄.
   **차단 가능한 것은 `arrow`와 `hex` 둘뿐이다.** 보스 투사체(`boss_bolt`·`boss_icebolt`·`shock`)는 일부러 뺐다.
4. **상태**: **실제 연결됨. 다만 편성을 크게 탄다.**
   이동 전투(궁수 4 + 주술사 2 + 서리술사 1) 60초 측정에서 **막은 피해 10~34**,
   같은 장면의 받은 피해는 **0~6**이었다(`docs/sim/BUILD_PROBE.md` 궁·지뢰 요새 · 쌍검·가시 근접 줄).
   **막는 일 자체는 크게 하고 있다.** 문제는 크기가 아니라 **조건**이다 —
   차단 가능한 적 투사체가 `arrow`·`hex` 둘뿐이라 궁수·주술사 계열이 없는 장면에서는
   근접 수호를 고르지 않는 한 아무 일도 하지 않는다(6절 SM-4).
   **시드 2개 측정이라 크기의 방향을 단정하지 않는다** — 앞선 실행에서는 막은 피해 8.0 · 받은 피해 12~20이었다.

### ⑧ 잔영 분신 (`echo`, `supports_a.gd:409`)

1. **보완**: 주무기의 **기본** 공격을 시간차로 한 번 더 만든다. 피해는 주무기 피해 × 0.45.
   **전투망치**(주기 1.4초의 느린 한 방)와 **검**(짧은 사거리)이 가장 크게 덕을 본다.
2. **개조 셋**: 교차(`cross`, 옆 84) · 잔류(`residual`, 지나온 자리 · 2.4초 · 3타) · 추격(`chase`, 대상 추격 3타).
   **분신이 서는 자리 규칙이 셋 다 다르다** — 잘 갈렸다.
   **다만 셋 중 하나는 사실상 필수다**(아래 4). "서로 다른 선택"이라기보다 "기본형을 쓸 수 있게 만드는 스위치"에 가깝다.
3. **사슬**: `주무기 기본 타격` → `echo_copy` 자격(`main_direct`만 허용, `supports_a.gd:538`) → 분신 생성 →
   분신 자리에서 사거리·모양·적중을 **다시 판정** → 타격 경로 이름 `echo_direct` → **감전 후속을 터뜨린다**(확인).
   분신의 타격은 다시 분신을 만들지 않는다(무한 복제 금지, 이중 잠금).
4. **상태**: **기본형은 효과가 약하거나 잘 안 보임** — 기본형은 공격 방향 **반대쪽 72**에 서는데
   검 사거리가 95라 앞의 적까지 `72 + 거리`가 되어 대부분 닿지 않는다.
   측정: 단일 대상 20초에 생성 36 · **타격 0**, 잔류 잔영을 넣으면 **타격 81**(`docs/sim/BUILD_PROBE.md`).
   개조 셋은 실제 연결됨.

### ⑨ 바람 정령 (`wind`, `supports_a.gd:633`)

1. **보완**: 발동 거리 120 안에 적이 있어야 분다. 밀어내기 150(등급 저항 적용).
   **관통창**(폭 14의 좁은 직선 — 붙으면 못 쓴다)과 **추적궁**(근접 45% 약화)이 잃어버린 거리를 되찾는다.
   **쌍검에게는 손해다** — 붙어야 하는데 적을 떼어 놓는다. 보정하지 않았다(설계 의도).
2. **개조 셋**: 넓은 돌풍(`broad`, 150° · 밀어내기 60%) · 압축 돌풍(`focused`, 45° · 160%) · 잔바람(`lingering`).
   **넓은 돌풍과 압축 돌풍은 같은 손잡이의 좌우다**(각도 ↔ 세기). 잔바람만 성격이 다르다 —
   밀어낸 경로에 2초짜리 둔화 바람이 남아 **밀어낸 자리가 지형이 된다.**
3. **사슬**: 돌풍 피해는 `support_direct`(감전 후속 가능). 밀어내기는 반드시 `PSupport.knock_dist`를 거쳐
   정예 0.35배 · 보스 0배가 되고 `st.move_swept`로 밀어 벽 안에 넣지 않는다.
   **잔바람의 둔화는 `e.chill`을 쓰지 않는다** — 직전 프레임 이동을 되돌리는 별도 방식이다(`supports_a.gd:736`).
   그래서 냉기를 보는 것들(공용 '서리' 파편 등)은 잔바람에 반응하지 않는다.
4. **상태**: 실제 연결됨. 6절 SM-3에 잔바람·냉기가 갈라져 있다는 관찰을 적었다.

### ⑩ 역병 나비 (`plague`, `supports_b.gd:242`)

1. **보완**: 독을 걸고, **감염된 적이 죽으면** 남은 시간을 물려받아 주변으로 옮는다.
   사슬이 이어지려면 적이 **빨리** 죽어야 하므로 **쌍검·검**처럼 단일·근접 화력이 높은 주무기와 맞는다.
   튼튼한 적에게는 사슬이 거의 이어지지 않는다(`docs/sim/SPREAD_PROBE.md` 2절).
2. **개조 셋**: 넓은 전염(`wide`, 범위 180 · 대상 +1 · 독 75%) · 깊은 맹독(`deep`, 독 150% · 대상 1 · 범위 80) ·
   역병 파열(`burst`, 죽으면 남은 독의 60%를 반경 90에 즉시).
   **넓은 전염과 깊은 맹독은 같은 손잡이의 좌우다**(퍼짐 ↔ 세기). 역병 파열만 성격이 다르다.
3. **사슬**: `나비가 독을 건다(gen 0)` → `감염된 적이 죽는다` → `plague_spread` 자격(출처를 가리지 않는다) →
   `세대 상한`(`gen_max`, 지금 2) → `남은 시간을 물려받아` 주변 n마리 감염 → 반복.
   **독은 여기 말고 아무 데도 이어지지 않는다** — 혈월검(`EQ.statusDirect`)조차 화상·출혈만 본다(`combat_state.gd:1418`).
4. **상태**: 실제 연결됨. 다만 파열과 전염이 **같은 자원**(살아 있는 이웃)을 먹어 함께 살지 못한다(`docs/SYNERGY.md` SYN-3).

### ⑪ 가시 갑각 (`thorns`, `supports_b.gd:118`·`supports_b.gd:382`)

1. **보완**: 근접 피해 20% 경감(이 보조 몫 상한 40%)과 근접 피격 시 반격(대기 0.6초).
   **쌍검**처럼 붙어 있는 시간이 가장 긴 주무기가 그대로 덕을 본다. 추적궁과는 결이 반대다.
2. **개조 셋**: 집중 가시(`focused`, 20° · 180%) · 가시 폭발(`burst`, 원형 110 · 60%) · 독가시(`venom`, 초당 4 · 3초).
   **집중 가시와 가시 폭발은 같은 손잡이의 좌우다**(모양 ↔ 세기). 독가시만 상태 공급이다.
3. **사슬**: `적의 근접 타격을 맞는다` → `thorns_reflect` 자격(`enemy_melee`만) → 반격.
   반격 피해의 경로 이름은 `reflect`라 **감전 후속을 못 터뜨린다**(자기 호출 금지의 일부).
   독가시의 독은 `spread=false`라 **역병 나비의 전염·파열 자격이 없다**(설계 확정).
   그리고 위에 적었듯 화상·출혈만 보는 혈월검도 이 독을 못 본다 → **독가시의 독은 어디에도 이어지지 않는다.**
4. **상태**: 실제 연결됨(경감·반격 모두 측정됨). 크기는 반격보다 **경감**이 크다
   (밀집 무리 40초에 반격 2~5회 · 경감 3.4~17.0, 같은 장면 받은 피해 17.2~34.4 —
   `docs/sim/BUILD_PROBE.md` 쌍검·가시 근접 줄).

### ⑫ 도깨비 인형 (`doll`, `supports_b.gd:441`)

1. **보완**: 근처에 미끼를 세우면 주변 적 일부가 **스스로 걸어간다**(강제 이동 없음).
   **전투망치**(예고 0.45초 — 적이 한 자리에 모여 있어야 맞는다)와 **추적궁**(거리를 벌어야 한다)이 가장 크게 덕을 본다.
2. **개조 셋 — 잘 갈렸다.** 질긴 인형(`tough`, 체력 1.8배 · 지속 1.5배)은 수치지만,
   폭죽 인형(`firework`)은 **인형을 적 한가운데 세울 이유**를 만들고,
   도망치는 인형(`fleeing`)은 **적을 끌고 가서 전선을 나눈다**. 셋의 쓰임이 실제로 다르다.
3. **사슬**: `인형을 세운다` → `유인 명단`(등급 저항 `taunt`: 정예 절반 · 보스 0) →
   `CombatState.target_of`·`approach`가 그 적의 표적을 인형으로 바꾼다(`combat_state.gd:661`·`677`) →
   `인형이 부서지거나 수명이 다한다` → (폭죽이면) 0.4초 예고 뒤 폭발(`doll_blast`, 감전 후속 없음).
4. **상태**: 유인은 **실제 연결됨**(늑대 8 편성 60초에 유인 18~21마리, 받은 피해 100 → 72~100,
   3시드 중 2시드가 패 → 승).
   **'대신 맞기'는 효과가 약하거나 잘 안 보임** — 같은 실행에서 대신 받음 **0회**(3시드 전부).
   앞선 실행에서는 1회 12 피해였다. **이 0은 '재지 못함'이 아니다** — `soaked`는 `METER_MAP`에 있어
   실제로 세는 지표다(7절). 값어치가 '대신 맞기'가 아니라 **'떼어 놓기'**에서 나온다.

## 3. 개조 36개 — 행동을 바꾸는 것 / 수치만 바꾸는 것

**판정 기준(하나만 썼다)**: 그 개조를 켰을 때 **플레이어가 다르게 움직여야 할 이유**가 생기는가
(공격 방식 · 위치 선정 · 적 처리 순서 중 하나). 생기면 '행동', 같은 자리에서 같은 순서로 싸워도 숫자만
달라지면 '수치'다. 자동으로 도는 추가 타격은 아무리 세도 '수치'다.

### 3-1. 행동을 바꾸는 것 — 16개

| 보조 | 개조 | 무엇이 달라지는가 |
|---|---|---|
| 번개 구체 | 축전(`conduct`) | 감전 후속 3회를 모아 반경 96 방전 → **적을 모아 두는 것이 이득**이 된다 |
| 서리 수정 | 차가운 바닥(`ground`) | 적중 지점에 2초 둔화 지대 → **그 위에서 싸울 이유**가 생긴다 |
| 불씨 정령 | 화염 띠(`trail`) | 착탄에서 플레이어 쪽으로 3조각이 이어진다 → **오는 길에 깐다** |
| 불씨 정령 | 재점화(`reignite`) | 불길 위 처치마다 +1.5초 → **어디로 몰아 죽일지**가 달라진다 |
| 룬 지뢰 | 연결 폭발(`chain`) | 90 안 다른 지뢰가 연달아 → **좁게 돌아 지뢰를 뭉쳐 깐다** |
| 룬 지뢰 | 유인 룬(`lure`) | 준비된 지뢰가 작은 적을 당긴다 → **적이 함정으로 걸어온다** |
| 추격 까마귀 | 집중 사냥(`hunt`) | 같은 적을 계속 → 최대 +60% → **표적을 바꾸지 않는 것이 이득** |
| 추격 까마귀 | 먹잇감 전환(`switch`) | 처치하면 다음 첫 공격 200% → **빨리 죽이고 갈아탄다** |
| 추격 까마귀 | 쌍둥이(`twin`) | 두 마리가 서로 다른 적 → **표적을 나눈다** |
| 잔영 분신 | 교차 잔영(`cross`) | 옆 84에 서서 **다른 각도**로 같은 적을 친다 |
| 잔영 분신 | 잔류 잔영(`residual`) | 지나온 자리에 2.4초 남는다 → **치고 빠지면 뒤가 계속 맞는다** |
| 잔영 분신 | 추격 잔영(`chase`) | 대상을 따라가 3타 → **한 적에 붙인다** |
| 바람 정령 | 잔바람(`lingering`) | 밀어낸 경로에 2초 둔화 → **밀어낸 자리가 지형이 된다** |
| 역병 나비 | 역병 파열(`burst`) | 죽는 자리에서 반경 90 즉시 방출 → **어디서 죽일지**가 중요해진다 |
| 도깨비 인형 | 폭죽 인형(`firework`) | 소멸 시 폭발 → **인형을 적 한가운데 세울 이유** |
| 도깨비 인형 | 도망치는 인형(`fleeing`) | 인형이 플레이어에게서 멀어진다 → **전선을 둘로 나눈다** |

### 3-2. 수치만 바꾸는 것 — 20개

| 보조 | 개조 | 실제로 바꾸는 것 |
|---|---|---|
| 회전 칼날 | 칼날 +1(`dual`) | 접촉 빈도(같은 궤도) |
| 회전 칼날 | 사출 칼날(`launch`) | 3초마다 자동 추가 타격 120%(표적 선택도 자동) |
| 회전 칼날 | 톱날(`serrated`) | 출혈 DoT 추가 — 다만 **출혈 공급원 자격**이 열린다 |
| 번개 구체 | 분기 번개(`fork`) | 연쇄 대상 수 |
| 번개 구체 | 순환 전류(`loop`) | 첫 대상에 1회 추가 |
| 서리 수정 | 서리 부채(`fan`) | 발사 수 3 |
| 서리 수정 | 깨지는 수정(`shatter`) | 적중당 파편 3(40%) |
| 불씨 정령 | 불씨 산개(`scatter`) | 불길 3개(각 70% 크기) — 배치가 자동이라 위치 선정은 안 바뀐다 |
| 룬 지뢰 | 서리 함정(`frosttrap`) | 폭발에 냉기 부여 — **냉기 공급원 자격**이 열린다 |
| 수호 방울 | 겹울림(`layered`) | 저장 +1 ↔ 충전 30% 느림 |
| 수호 방울 | 근접 수호(`guard`) | 근접 한 대 50% 경감(같은 충전, **자동 소모**라 선택권이 없다) |
| 수호 방울 | 되돌림(`reflect`) | 차단할 때마다 반격탄 12 |
| 바람 정령 | 넓은 돌풍(`broad`) | 각도 150° ↔ 밀어내기 60% |
| 바람 정령 | 압축 돌풍(`focused`) | 각도 45° ↔ 밀어내기 160% |
| 역병 나비 | 넓은 전염(`wide`) | 범위 180 · 대상 +1 ↔ 독 75% |
| 역병 나비 | 깊은 맹독(`deep`) | 독 150% ↔ 대상 1 · 범위 80 |
| 가시 갑각 | 집중 가시(`focused`) | 20° ↔ 180% |
| 가시 갑각 | 가시 폭발(`burst`) | 원형 110 ↔ 60% |
| 가시 갑각 | 독가시(`venom`) | 반격에 독 4/3초 — **어디에도 이어지지 않는다**(6절 SM-1) |
| 도깨비 인형 | 질긴 인형(`tough`) | 체력 1.8배 · 지속 1.5배 |

### 3-3. '같은 손잡이의 좌우'라 선택이 갈리지 않는 짝 — 5쌍

아래 다섯 쌍은 **한 축의 양끝**이라 "다른 플레이"가 아니라 "같은 플레이의 세기 조절"이다.
셋 중 둘이 이 관계면 사실상 두 갈래짜리 선택이 된다.

| 보조 | 짝 | 축 |
|---|---|---|
| 번개 구체 | 분기 ↔ 순환 | 연쇄를 얼마나 더 하는가 |
| 서리 수정 | 부채 ↔ 파편 | 얼마나 더 많이 맞히는가 |
| 바람 정령 | 넓은 돌풍 ↔ 압축 돌풍 | 각도 ↔ 밀어내기 세기 |
| 역병 나비 | 넓은 전염 ↔ 깊은 맹독 | 퍼짐 ↔ 독 세기 |
| 가시 갑각 | 집중 가시 ↔ 가시 폭발 | 반격 모양 ↔ 세기 |

### 3-4. 보조별 개수 — 어디가 잘 갈리고 어디가 안 갈리는가

| 보조 | 행동 | 수치 | 한 줄 평 |
|---|---:|---:|---|
| 추격 까마귀 | **3** | 0 | 셋이 전부 표적 정책이라 가장 잘 갈렸다 |
| 잔영 분신 | **3** | 0 | 셋이 전부 분신이 서는 자리다. 다만 기본형이 거의 못 때려 '고쳐 쓰는 스위치'에 가깝다 |
| 불씨 정령 | 2 | 1 | 화염 띠·재점화가 갈리고 산개만 수치 |
| 룬 지뢰 | 2 | 1 | 연결 폭발·유인 룬이 갈리고 서리 함정만 수치 |
| 도깨비 인형 | 2 | 1 | 폭죽·도망이 갈리고 질긴 인형만 수치 |
| 번개 구체 | 1 | 2 | 분기·순환이 한 축이라 겹친다 |
| 서리 수정 | 1 | 2 | 부채·파편이 한 축이라 겹친다 |
| 바람 정령 | 1 | 2 | 넓은·압축이 같은 손잡이의 좌우 |
| 역병 나비 | 1 | 2 | 넓은·깊은이 같은 손잡이의 좌우 |
| **회전 칼날** | **0** | 3 | **셋 다 "더 많이 때린다"** — 선택이 사실상 하나다 |
| **수호 방울** | **0** | 3 | 역할은 갈리지만 전부 자동이라 플레이가 안 바뀐다 |
| **가시 갑각** | **0** | 3 | 집중·폭발이 한 축이고 독가시는 이어지는 곳이 없다 |

**셋이 전부 행동을 바꾸는 보조는 둘**(추격 까마귀 · 잔영 분신), **셋이 전부 수치인 보조는 셋**(회전 칼날 · 수호 방울 · 가시 갑각)이다.

## 5. 공급 → 소비 사슬 지도 — 여기가 시너지가 비어 있는 곳이다

**같은 상태를 여러 보조가 공급하는 것은 문제가 아니다.** 문제는 **받아 주는 쪽**이다.

| 상태·자원 | 공급하는 쪽 | 받아 추가 효과를 내는 쪽 | 판정 |
|---|---|---|---|
| **감전**(`conduct`) | 번개 구체 기본 연쇄 하나 | 주무기 직접 · 주무기 개조 추가 · 보조 직접 · 분신 모방 **넷** + 축전 방전 | **잘 이어졌다**(공급 1 : 소비 5) |
| **불길 장판** | 불씨 정령(개조 3개 모두) | 공용 증강 '불꽃 파열'(연쇄 처치 9) · 재점화(자기 자신) | 이어졌다. **다만 소비자가 보조가 아니라 공용 증강** |
| **냉기**(`chill`) | 서리 수정 · 차가운 바닥 · 서리 함정(지뢰) · 공용 '서리' | 이동 속도 0.6배 + **공용 '서리'의 처치 시 파편 하나뿐** | **비어 있다** — 보조 중 냉기를 소비하는 것이 0 |
| **독**(`plague`) | 역병 나비 · 독가시(가시 갑각) | 전염·파열(역병 나비 자기 자신)뿐. 독가시의 독은 그것도 자격 없음 | **거의 비어 있다** |
| **출혈**(`bleed`) | 톱날(회전 칼날) · 출혈 칼날(쌍검) | 혈월검(`EQ.statusDirect`)·희귀 보상 자격 | 장비로만 이어진다 |
| **밀어내기·둔화(잔바람)** | 바람 정령 · 전투망치 · 유인 룬 | 위치가 바뀌는 것 자체 | 이어졌다(상태가 아니라 위치라 소비자가 필요 없다) |
| **유인**(인형) | 도깨비 인형 | `CombatState.target_of`·`approach` | 이어졌다 |
| **반사 피해** | 가시 갑각 · 되돌림(수호 방울) | 없음(자기 호출 금지로 일부러 막았다) | 의도대로 |

### 5-1. 가장 눈에 띄는 두 가지

1. **냉기가 아무 데도 안 이어진다.** 냉기 공급원은 넷이나 되는데(서리 탄환·차가운 바닥·서리 함정·공용 서리)
   그 상태를 읽어 추가 효과를 내는 것은 공용 증강 '서리'의 얼음 파편 하나뿐이다.
   감전이 "걸면 다음 타격이 터진다"인 것과 대비된다. **공급이 겹쳐서가 아니라 소비가 없어서 안 보인다.**
2. **바람의 잔바람 둔화와 냉기가 서로 다른 경로다.** 잔바람은 `e.chill`을 쓰지 않고
   직전 프레임 이동을 되돌리는 방식이라(`supports_a.gd:736`) 냉기를 읽는 것들이 잔바람에 반응하지 않는다.
   **같은 '둔화'로 보이지만 코드에서는 남남이다.**

## 6. 결함·관찰 기록 (고치지 않았다 — 그 파일이 이 담당의 소유가 아니다)

### SM-1 · 독가시(가시 갑각)의 독은 어디에도 이어지지 않는다

- **기대**: 개조 설명은 "반격 가시에 독을 묻힌다"이고, 역병 나비의 전염·파열 자격이 없는 것은 설계 확정이다.
  그렇더라도 **독 상태를 읽는 다른 곳**이 하나쯤은 있어야 '상태를 공급하는 개조'로서 뜻이 산다.
- **실제**: 하나도 없다. 혈월검(`EQ.statusDirect`)조차 `combat_state.gd:1418`에서
  `e.burn`과 `e.bleed`만 본다 — `e.plague`는 보지 않는다.
- **재현**: `combat_state.gd:1418`을 읽으면 조건이 보인다.
  `grep -n "statusDirect" scripts/rules/combat_state.gd` → 한 곳뿐.
- **판단**: 독가시는 지금 **"초당 4의 지속 피해"** 그 이상도 이하도 아니다. 3절에서 '수치만 바꾼다'로 넣은 이유다.
- **고치지 않았다** — `scripts/**`는 이 담당의 소유가 아니다.

### SM-2 · 유인 룬(룬 지뢰)이 등급 저항을 거치지 않는다

- **기대**: 위치를 강제로 바꾸는 것은 전부 `PSupport.knock_dist`나 `PSupport.resist_mult`를 거쳐
  정예는 약하게, 보스는 0이 되어야 한다(`data/supports.json` `resist.why`, 지시 5절).
- **실제**: `weapons.gd:596`~`602`가 `if not e.boss and not bool(e.airborne)`만 보고
  `st.move_swept(e, n[0] * 40.0 * dt, ...)`로 그대로 당긴다. **보스만 제외되고 정예는 온전히 끌린다.**
  같은 파일의 다른 밀어내기(바람 정령 `supports_a.gd:684`)는 `knock_dist`를 거친다.
- **재현**: `python tools/run_suites.py --suites synergy_tests --jobs 1` →
  `DEFECT SM-2 ... 정예가 18.0만큼 끌려왔다` 줄(`tests/synergy_tests.gd` 8절 끝).
  코드는 `grep -n "has(\"lure\")" scripts/rules/weapons.gd` → 596행 부근.
- **결함 기록이지 단언 실패가 아니다** — 규칙 코드는 이 담당이 고칠 수 없으므로
  `synergy_tests`는 이것을 `DEFECT`로만 찍고 통과 수에서 빼지 않는다.
- **고치는 방향(제안, 적용하지 않음)**: 당기는 거리에도 `PSupport.knock_dist(40.0 * dt, e)`를 쓰면
  정예 0.35배 · 보스 0으로 한 곳에서 정리된다. **수치 변화가 따라오는 변경이라 사용자 확인이 필요하다.**
- **처리(2026-09-09, 규칙 담당): 고쳤다.** 당기는 거리에 `PSupport.knock_dist(40.0 * dt, e)`를 넣었다.
  **자격표를 새로 만든 것이 아니라 이미 있는 표를 지키게 한 것**이라(같은 파일 356행의 '연결 폭발'은 처음부터 그렇게 돌고 있었다)
  사용자 승인이 필요한 밸런스 값 변경으로 보지 않았다. 정예는 0.35배(0.1초에 4.00 → 1.40px), 보스는 그대로 0이다.
  `synergy_tests` 8절의 `DEFECT SM-2`를 **회귀 단언 셋**으로 바꿨다(일반은 끌려온다 / 정예는 덜 끌려온다 / 배율이 자격표와 맞는다).
  **효과가 줄어드는 방향이므로 유인 룬이 정예 상대로 여전히 쓸 만한지는 사람이 판단할 몫이다.**


### SM-3 · '둔화'가 두 갈래로 갈라져 있다 (관찰)

- 냉기(`e.chill`)는 `enemy_speed_mult`가 읽고, 잔바람은 이동 되돌리기다(`supports_a.gd:736`).
  둘 다 `PSupport.stack_slow`의 최저 속도(0.35)를 지키지만 **서로를 모른다.**
- 결과: 냉기를 읽는 것(공용 '서리'의 처치 시 파편)이 잔바람에는 반응하지 않는다.
  화면 표시도 갈릴 수 있다(이 담당이 확인하지 않았다 — `render.gd`는 소유가 아니다).
- **결함이라고 단정하지 않는다.** 이동 속도 배율을 쓰는 공용 훅이 없어 바람이 다른 방법을 쓸 수밖에 없었다는
  주석이 이미 코드에 있다. 여기 적는 것은 **"같은 둔화로 보이지만 이어지지 않는다"**는 사실을 남기기 위해서다.

### SM-4 · 수호 방울이 막을 수 있는 것이 두 종류뿐이다 (관찰)

- `data/supports.json` `bell.base.incoming.blockable`은 `arrow`와 `hex` 둘이다.
  보스 투사체를 뺀 것은 명시적 설계다("보스를 방울 두 개로 무력화하지 않기 위해서다").
- 그런데 실제 편성에서 이 둘을 쏘는 것은 궁수 계열과 주술사 계열뿐이라,
  **그 둘이 없는 장면에서는 방울이 아무 일도 하지 않는다**(근접 수호를 고르지 않았다면).
- 측정: 이동 전투(궁수 4 + 주술사 2 + 서리술사 1) 60초에 막은 피해 **10~34**(같은 장면 받은 피해 0~6).
  **막는 일 자체는 크다** — 좁은 것은 크기가 아니라 '무엇을 막을 수 있는가'다.
- **값을 바꾸지 않았다** — `blockable` 목록을 늘릴지는 사용자 결정이다.

### SM-5 · 기본형 잔영 분신이 단일 대상에서 거의 못 때린다

- **기대**: 개조 없이도 "주무기의 기본 공격을 따라 한다"가 성립해야 한다.
- **실제**: 기본형은 공격 방향 **반대쪽 `offset`(72)**에 선다(`supports_a.gd:591`).
  분신 자리에서 사거리를 다시 재므로 검(95)이면 적이 플레이어에게서 23 이내여야 닿는다.
  측정: 단일 대상 20초 **생성 36 · 타격 0**, 잔류 잔영을 넣으면 **타격 81**(`docs/sim/BUILD_PROBE.md`).
- **판단**: 개조 셋 중 하나를 고르기 전까지는 이 보조가 사실상 아무것도 하지 않는다.
  3절에서 잔영 분신의 개조 셋을 "서로 다른 선택"이자 동시에 "기본형을 쓸 수 있게 만드는 스위치"라고 적은 이유다.
- **고치지 않았다.**

## 7. 무엇이 미계측인가 (0으로 적지 않은 것)

`PSupport.is_metered(id)`는 12종 모두 참을 돌려주지만, **실제로 세는 지표는 보조마다 다르다.**
아래에서 '없음'은 **0이 아니라 재지 못했다**는 뜻이다.

| 보조 | 세는 지표 | 없는 지표(=미계측) |
|---|---|---|
| 회전 칼날 | `hits` · `dmg` | `fires` |
| 번개 구체 | `shocks` · `shock_procs` · `shock_dmg` · `discharges` | **기본 연쇄의 `fires`·`hits`·`dmg`** |
| 서리 수정 | `fires` · `slows` | `hits` · `dmg` · `slow_sec` |
| 불씨 정령 | `fires` | `hits` · `dmg`(장판 틱이 무기 출처로만 남는다) |
| 룬 지뢰 | `blasts` | `fires` · `hits` · `dmg` |
| 추격 까마귀 | `marks` · `hits` · `dmg` | `mark_keeps`(표적 유지 프레임) |
| 수호 방울 | `blocked` · `blocked_dmg` · `guards` · `reduced_dmg` · `reflects` · `reflect_dmg` | — |
| 잔영 분신 | `copies` · `hits` · `copy_dmg` | `fizzles`(대상을 못 찾은 횟수)는 내부에만 있고 표준 이름으로 안 나온다 |
| 바람 정령 | `fires` · `push_dist` · `slows` | `slow_sec` |
| 역병 나비 | `fires` · `spreads` · `bursts` · `dmg` · `dot_dmg` | — |
| 가시 갑각 | `reduced_dmg` · `reflects` · `hits` · `reflect_dmg` | — |
| 도깨비 인형 | `fires` · `taunted` · `soaked` · `soaked_dmg` | 인형이 버틴 시간 |

### 7-1. 개조 귀속(`note_mod`)이 없는 개조 — 15개

`st.note_mod(개조, "proc")`을 부르지 않는 개조는 **발동 횟수를 셀 수 없다.**
보고서에서 그 개조의 발동을 0으로 적으면 안 된다.

|---|---|
| 회전 칼날 | dual · launch · serrated (셋 다) |
| 번개 구체 | fork · loop (축전의 방전만 `discharges`로 센다) |
| 서리 수정 | ground (fan · shatter는 있다) |
| 불씨 정령 | scatter · trail · reignite (셋 다) |
| 룬 지뢰 | chain · frosttrap · lure (셋 다) |
| 수호 방울 | layered |
| 바람 정령 | lingering (broad · focused는 있다) |
| 도깨비 인형 | fleeing |

### 7-2. 처치의 원인을 셀 수 없다

`CombatState.kill_enemy(e, o)`가 `o`(출처)를 받으면서도 어디에도 남기지 않는다.
그래서 **'연쇄 처치 수'를 출처별로 정확히 셀 수 없다.** 지금은 (가) 한 프레임에 2마리 이상 죽은 횟수와
(나) 직접 타격 밖 경로의 피해 비율로 대신하고 있고, 둘 다 근사다(`docs/SYNERGY.md` SYN-5).

## 8. 이 문서가 재지 않은 것(범위를 줄였다고 적는다)

- **보스를 넣지 않았다.** 제압 저항이 0인 보스에서는 밀어내기·유인·경직 축이 통째로 사라진다.
- **정예를 따로 재지 않았다.** 저항 0.35~0.6이 걸리는 구간의 체감은 이 문서의 근거에 없다.
- 개조 조합(보조 2종 × 각 1개조)의 전수 비교를 하지 않았다. 대표 빌드 10개만 있다(`docs/sim/BUILD_PROBE.md`).
- **3절의 '행동 / 수치' 분류는 코드를 읽고 내린 판단이다.** 봇 계측으로 "플레이가 실제로 달라졌다"를
  확인한 것이 아니다 — 그것을 재려면 같은 장면에서 봇의 이동·표적 선택이 개조에 따라 달라지는지를
  봐야 하고, 이번에 만들지 않았다.

# 실제 속도 영상 클립 (0.9.x — 새 보조무기·연계·보스 장애물 파괴)

**연속 프레임 묶음이 아니라 재생되는 영상 파일이다.** Godot Movie Maker(`--write-movie … --fixed-fps 24`)로 찍었고,
`--fixed-fps`가 한 프레임을 정확히 1/24초로 고정하므로 파일을 그대로 재생하면 게임이 **실제 속도**로 움직인다.

## 촬영을 위해 규칙을 바꾸지 않았다

- 판정·수명·피해·시간 배율은 그대로다(`time_scale = 1`). 규칙 코드에 촬영용 분기는 없다.
- 고른 것은 세 가지뿐이다: **어떤 장면을 띄울지**(`PROPHECY_CLIP`) · **누가 조종할지**(`bot`) · **얼마나 볼지**(초).
- 방어 보조(가시 갑각·수호 방울·도깨비 인형)와 보스 파괴 클립은 **정해진 이동 입력**을 쓴다.
  규칙 우회가 아니라 사람이 할 수 있는 조작이며, 공격·회피·피해 계산은 평소 그대로다.

## 왜 그런 선택을 했는지 — 숨기지 않고 적는다

**방어 보조는 "맞아야" 일한다.** 처음에는 실제 출격(습지 4일차)에서 균형 봇으로 찍었는데,
가시 갑각이 12초 내내 **한 번도 발동하지 않았다**(반격 0 · 경감 0). 봇이 잘 피해서 근접 접촉이 없었기 때문이다.
콘텐츠가 약해서가 아니라 **잴 기회가 없었다.** 그래서 늑대 10기를 세우고 초보 봇으로 바꿨다.

**보스 파괴도 마찬가지다.** 파괴는 "엄폐에 막힌 채 1초 이상"이 자격인데, 평소처럼 돌아다니는 봇으로는
7초 동안 **한 번도 부수지 않았다**(부순 장애물 0). 사람이 실제로 겪은 문제(바위 뒤에서 불씨로 일방 공격)를
그대로 재현하려면 **엄폐 뒤에 서 있어야** 한다. 그래서 `cover` 조작을 넣었다.

## 찍은 것 — 그 효과가 **실제로 일어났는지**를 함께 적는다

같은 설정을 헤드리스로 한 번 더 돌려(`--fixed-fps 24`) 얻은 수치다. 파일이 만들어졌다는 것과 효과가 보인다는 것은 다른 말이다.

## 찍은 명령

```sh
# 클립 하나
PROPHECY_CLIP=<이름> PROPHECY_CLIP_SEC=<초> PROPHECY_CLIP_FPS=24 \
  godot --path prophecy_godot \
        --write-movie docs/captures/0.9.0_clips/<이름>.avi --fixed-fps 24
```

- `--write-movie` 경로는 **프로젝트 폴더 기준**이다(저장소 기준으로 적으면 `prophecy_godot/prophecy_godot/…`에 만들어진다).
- 같은 명령에서 `--write-movie`를 빼고 `--headless`를 붙이면 **영상 없이 수치만** 확인할 수 있다. 위 표의 마지막 칸이 그것이다.
- 길이는 프레임 수로 센다. `--fixed-fps`와 `PROPHECY_CLIP_FPS`를 같게 두면 파일 길이가 정확히 그 초가 된다.
- `.avi`는 저장소에 넣지 않는다(초당 약 1.5 MB). 위 명령으로 언제든 다시 만든다.

## 아직 못 찍은 것

- **신규 몬스터 3종(흡혈 박쥐·불씨 도마뱀·도약 두꺼비)** · **일반 정예 확장** · **테마별 대표 협공** ·
  **특수 정예 결투 전환** — 아직 구현 중이다. 구현이 끝나면 같은 방식으로 찍는다.
- 새 보조 일부는 **화면에 그려지지 않는다**(추격 까마귀 몸체·잔영 분신·도깨비 인형 몸체·잔바람 장판).
  수치는 위 표대로 실제로 발동하지만 **눈으로는 잘 안 보인다.** 화면 표시는 별도 작업이다.

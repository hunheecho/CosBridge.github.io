# 실제 속도 영상 클립 — §11-A 보스 신규 공격 패턴 18개 (2026-09-10)

Godot Movie Maker로 찍었다. `--fixed-fps 30`이 한 프레임을 정확히 1/30초로 고정하므로
파일을 그대로 재생하면 게임이 **실제 속도**로 움직인다.

```
PROPHECY_CLIP=<이름> PROPHECY_CLIP_SEC=<초> PROPHECY_CLIP_FPS=30 \
  godot --path prophecy_godot --resolution 1280x720 --write-movie docs/captures/nx_clips/<이름>.avi --fixed-fps 30
python tools/clip_check.py docs/captures/nx_clips/<이름>.avi --expect-sec <초> --save <장수> --out <폴더>
```

촬영을 위해 규칙을 바꾸지 않았다. 판정·수명·피해·시간 배율(`time_scale = 1`)은 그대로이고,
`main.gd`에는 **CLIPS 항목만** 더했다. 조종은 기존 봇(balanced)이다.

## 아직 눈으로 못 본 것 (정직 기록)

18개 중 위 여섯 장면 밖의 패턴(길목 덮치기 착지 원, 전진 연사 조준선, 암석 굴리기의 구르는 바위·파열 원,
추격 도약, 처형 행진, 교차 얼음창, 측면 추격, 몰이 사냥, 진격 강타, 봉인 협공, 잔향 추격, 미래 표식)은
**같은 클립 안에 들어 있을 수 있으나 뽑은 표본 프레임에서 직접 보지는 못했다.**
그 12개는 규칙 시험(`tests/boss_tests.gd`의 신규 패턴 시험 — 예고 도형·확정 불변·회피 가능·빈틈·실전 사용)으로만 확인했다.

`.avi` 원본은 저장소에 넣지 않는다(편당 18MB). 위 명령으로 언제든 다시 찍을 수 있다.

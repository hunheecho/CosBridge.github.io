# 웹 빌드 한글 글꼴 확인 (2026-09-09 · 커밋 9bd00bd 기준 작업본)

**무엇을 보았나.** 글꼴을 넣은 웹 빌드를 이 PC에서만 띄우고(`127.0.0.1`), 브라우저로 열어
**한글이 네모(□) 없이 나오는지**를 화면마다 눈으로 확인했다. 아래 그림이 그 기록이다.

## 만든 방법

```
python tools/export_web.py --out ../prophecy_godot_build/web_font_9bd00bd
python tools/serve_web.py  --dir ../prophecy_godot_build/web_font_9bd00bd --port 8792
```

- 서버는 `127.0.0.1:8792`에만 묶였고 **확인이 끝난 뒤 껐다**(포트 닫힌 것까지 확인). 외부 공개 배포는 하지 않았다.
- 브라우저는 이 PC의 크롬(Chrome, headless=new)을 개발자 도구 프로토콜로 조종해 열고 눌렀다.
  화면 그림은 브라우저가 실제로 그린 것을 그대로 받은 것이다(엔진 스크린샷이 아니다).
- 콘솔 오류 0건. 로그는 엔진 3줄뿐이다: `Godot Engine v4.7.2.stable`,
  `OpenGL ES 3.0 (WebGL 2.0 …)`, `Emscripten 4.0.20, single-threaded, no GDExtension support`.

## 설계 가정(플레이로 검증 필요)
- **접촉 피해 없음**: 모든 피해는 예고된 공격·지역에서만. 가독성을 위해 택했으나 "늑대에 둘러싸여도 무섭지 않다"는 문제가 생길 수 있음.
- **자동 공격은 대상이 사거리 안일 때만**: 허공 휘두르기가 없어 "왜 안 때리지" 혼란을 줄이려 했으나, 반대로 공격 리듬이 끊겨 보일 수 있음.
- **마우스 조준 없음**: 캐주얼 조작 우선. 원거리 적 상대 시 답답할 수 있음.
- **웨이브 사이 1.2초 대기**와 **가장자리 등장 경고 0.6초**.
- **더 깊이 탐험**은 같은 지역 강화 조우 1회로 한정.
- **표식 이동**: 더 위험한 적이 나타나면 표식이 옮겨간다(첫 구현 규칙).
- **화면 밖 위협 표시 없음**: 전장이 한 화면에 다 들어오므로 생략.
- **캐릭터 시각 배율 1.25**: 그림이 판정 원보다 조금 크다. 늑대는 몸이 길어 돌진 방향으로는 판정보다 그림이 더 나간다(빗나간 듯 보이는데 맞는 경우가 생기면 배율·판정 조정).
- **측면 시점 캐릭터 + 위에서 본 전장**: 뱀서류 관례. 위/아래 이동 시 캐릭터가 옆을 보는 것은 의도.

# 예언의 시간표: 액션 프로토타입 — 게임 명세 (현재 규칙)

이 문서는 **현재 코드가 실제로 따르는 규칙**을 적는다. 미확정 수치는 `docs/ASSUMPTIONS.md`에 임시값으로 표시하고, 전체 기획과 개발 순서는 `docs/TRACEABILITY.md`에서 추적한다.

## 0. 한 문장 요약
마검사가 보스가 도래하기 전 며칠 동안 하루 5시간을 배분해 지역으로 출격하고, **짧은 실시간 전투**에서 적의 예고를 읽어 대응하며, 증강·장비로 공격 형태를 바꿔 다음 전투를 다르게 푼다.

## 1. 시간 구조 (네 층위)
| 층위 | 정의 | 유지되는 것 | 초기화되는 것 |
|---|---|---|---|
| 개별 전투(조우) | 한 지역에서의 40~120초 실시간 전투 | 체력, 증강, 장비, 획득물 | 보호막, 특수기 재사용, 전장 효과(불길·구름·표식) |
| 하루 | 5시간 예산. 출격·휴식으로 소모 | 위와 동일 + 금화·재료 | 남은 시간(5로), 체력(가득) |
| 회차 | 1일차부터 보스 도래일(7일차 시작)까지 | 증강·장비·금화·재료·날짜 | 새 회차 시작 시 전부 |
| 회차 간 영구 해금 | **첫 버전에 없음**(기획 보류, 추적표 R-META-01) | — | — |

## 2. 조작 (화면 하단에 상시 표시)
| 입력 | 동작 |
|---|---|
| W A S D / 방향키 | 이동 |
| Space | 회피(구르기) |
| Q | 특수기(감속장) |
| Esc | 일시정지(전투 정지) |
| Enter / 클릭 | 메뉴 확인 |
| F3 | 디버그 오버레이(개발용, 기본 꺼짐) |

- 마우스 조준 없음. 회피 방향은 현재 이동 입력, 없으면 마지막 바라보는 방향.
- 자동 공격은 어떤 입력도 막지 않는다. 회피 중에도 자동 공격은 계속된다.
- 선택 화면·일시정지·포커스 이탈(창 전환) 시 시뮬레이션은 완전히 멈춘다.

## 3. 플레이어
- 체력 100(장비로 증가), 이동 속도 220px/s, 판정 반지름 14.
- **보호막**은 체력과 별도 게이지(청록). 피해는 보호막 → 체력 순으로 적용.
- **피격 보호**: 피해를 받으면 0.6초 동안 추가 타격 무효(점멸). 같은 프레임에 겹친 여러 적의 공격은 최대 1회만 적용된다.
- **지역 피해(포자 구름 등)**: 0.5초마다 1틱. 겹친 지역이 여러 개여도 틱당 가장 큰 피해 1회만. 피격 보호를 무시하지만 회피 무적은 존중한다.
- **패배**: 체력 0 → 조우 즉시 종료(§9).

### 3.1 자동 공격 규칙(확정 기본값)
- **발동 조건**: 사거리 안에 적이 있을 때만 주기마다 발동. 빈 허공에 휘두르지 않는다.
- **대상**: (1) 사냥꾼의 표식 대상이 사거리 안이면 그 대상, (2) 아니면 가장 가까운 적.
- **방향**: 발동 순간 대상의 위치. 발동 후 방향은 바뀌지 않는다.
- **판정**: 발동 프레임에 1회. 한 번의 검격은 한 적에게 최대 1회 피해.
- **표시**: 부채꼴/직선 잔상이 0.15초 남고, 사거리는 플레이어 주변 옅은 원으로 상시 표시.

### 3.2 공격 형태(무기)
| 형태 | 획득 | 판정 | 특징 |
|---|---|---|---|
| 검격(기본검) | 시작 | 반지름 95, 각도 110° 부채꼴 | 정면 다수 |
| 관통 검격(관통검) | 대장간 제작 | 길이 230, 폭 44 직선, 관통 | 일렬로 모인 적 처리 |
| 회전 검격 | 증강 | 3번째 검격마다 360° 반지름 110 | 둘러싼 적 처리, 넉백 큼 |

무기 효과는 "형태", 증강은 "성능·행동·결합"으로 구분한다.

### 3.3 회피
- 지속 0.26초, 이동 150px, **전 구간 무적**. 종료 후 재사용 0.9초.
- **아슬아슬한 회피**: 회피 무적 구간에 적의 공격이 실제로 닿았다면 "회피!" 표시. 시간 저축 증강이 있으면 특수기 재사용 -4초.

### 3.4 특수기: 감속장(수동 슬롯 1)
- Q. 플레이어 위치에 반지름 150 원, 3.0초 지속. 안의 적·투사체는 속도와 준비 시간이 40%로 느려진다.
- 재사용 14초(장비로 감소). 조우 시작 시 즉시 사용 가능.
- 수동 슬롯은 1개. 이후 기술이 늘어도 슬롯 수는 늘리지 않고 교체한다(추적표 R-CTRL-03).

## 4. 적
공통: 회복 중(빈틈) 상태의 적은 받는 피해 1.5배, 머리 위에 어지러움 표시. 적끼리는 서로 밀어내 완전히 겹치지 않는다. 적은 서로 접촉해도 플레이어에게 **접촉 피해를 주지 않는다**. 모든 피해는 예고된 공격과 지역에서만 나온다.

### 4.1 늑대 — 역할: 돌진 습격
| 단계 | 시간 | 표시 | 규칙 |
|---|---|---|---|
| 접근 | — | 걷기 | 150px/s로 접근, 170px 안이면 준비 |
| 준비(웅크림) | 0.6초 | 몸이 낮아지고 **붉은 화살표**가 플레이어를 따라 회전 | 이 동안은 방향 추적 |
| 확정 | 0.15초 | 화살표 굵어지고 밝게 점멸 | **방향 고정**. 이후 절대 바꾸지 않음 |
| 돌진 | 0.32초 | 잔상 | 800px/s 직진. 벽에서 정지. 접촉 시 12 피해(1회) |
| 빈틈 | 0.9초 | 어지러움 표시 | 이동 불가, 피해 1.5배 |
- 기본 대응: 확정 신호를 보고 **옆으로** 이동/회피.
- 빌드 대응: 잔불 걸음(회피 자리에 불길 → 돌진 경로가 불길 통과), 관통(일렬 돌진 후 정렬된 늑대 처리).
- 조합: 궁수와 같이 있으면 돌진을 피한 위치가 화살 궤적과 겹치는지 판단해야 한다.

### 4.2 늑대 우두머리(정예) — 역할: 정예 처치 목표
- 체력 120, 반지름 22, 물기 18. **연속 2회 돌진**(두 번째 준비 0.35초). 빈틈 1.2초.

### 4.3 궁수 — 역할: 원거리 압박
| 단계 | 시간 | 표시 | 규칙 |
|---|---|---|---|
| 거리 유지 | — | — | 220px 안이면 후퇴(110px/s), 360px 밖이면 접근 |
| 조준 | 1.0초 | 가는 붉은 선이 플레이어를 따라감 | 방향 추적 |
| 확정 | 0.25초 | 선이 굵어짐 | 방향 고정 |
| 발사 | — | 화살 | 460px/s, 피해 10, 벽에서 소멸 |
| 빈틈 | 1.3초 | 어지러움 | 이동 불가 |
- 기본 대응: 선을 보고 옆으로, 접근해서 우선 처치(체력 22). 빌드: 표식(자동 우선 공격), 관통(멀리서도 직선 판정).

### 4.4 포자 괴물 — 역할: 지역 통제
| 단계 | 시간 | 표시 | 규칙 |
|---|---|---|---|
| 접근 | — | 느리게(60px/s) | 130px 안이면 준비 |
| 부풀기 | 0.9초 | 바닥에 커지는 보라 원(최종 반지름 80) | 표시 원 = 실제 구름 범위 |
| 파열 | — | 구름 생성 | 반지름 80, 5초, 0.5초마다 6 피해 |
| 빈틈 | 1.6초 | 어지러움 | — |
- 사망 시 반지름 50, 3초 구름을 남긴다.
- 기본 대응: 표시 원 밖으로. 구름이 남기 때문에 안전한 공간이 줄어들며, 늑대 돌진 회피 경로를 미리 계산해야 한다.

### 4.5 기획에 있으나 첫 구현에 없는 적
멧돼지(장애물 충돌 경직), 주술사(강화·회복), 방패병(정면 방어). 추적표 R-ENEMY-05~07.

## 5. 성장
### 5.1 구분
- **기술 습득**: 새 전투 수단(현재: 감속장 1개. 슬롯 교체는 후속).
- **무기 변형**: 기본 공격 형태 변화(관통검, 회전 검격).
- **일반 증강**: 수치·편의(예리한 날, 넓은 검격, 빠른 손).
- **결합 증강**: 조건이 있는 새 규칙(정지된 칼날, 불꽃 파열).

### 5.2 증강 목록(현재 구현)
| ID | 이름 | 종류 | 효과 | 조건/중첩 |
|---|---|---|---|---|
| sharp | 예리한 날 | 일반 | 공격력 +25% | 3단계 |
| wide | 넓은 검격 | 일반 | 검격 범위 +25% | 3단계 |
| quick | 빠른 손 | 일반 | 공격 주기 -15% | 3단계 |

- 조우 승리마다 3개 제시. 조건 미충족·최대 단계·이미 보유는 제시하지 않는다(무효 선택 방지).
- 선택 화면에는 "현재 빌드와의 연결" 문구를 표시한다(예: 관통검 보유 시 넓은 검격 → "관통 길이 +25%").
- 건너뛰기: 금화 +20.

## 6. 장비와 경제
- 슬롯: 무기 / 방어구 / 장신구. 무기 강화 +3까지.
- 상점·대장간은 **거점에서 항상 전 목록을 보여준다**(살 수 없어도). 각 항목에 필요한 금화·재료와 **재료 획득 지역**을 표시한다.
- **목표 장비**: 원하는 항목을 목표로 지정하면 거점 상단에 부족분과 획득 지역이 뜬다. 기본 목표는 관통검.
- 재료는 팔 수 있다(보관 vs 현금화 선택).
- 구매·제작 즉시 장착·효과 반영. 전투 전 대비 수치(피해, 늑대 처치 필요 타격 수)를 실제 계산으로 표시한다.

| 항목 | 비용 | 효과 |
|---|---|---|
| 관통검 | 260금 + 늑대 가죽 3 + 철 조각 2 | 기본 공격 → 관통 검격 |
| 가죽 갑옷 | 120금 + 늑대 가죽 2 | 최대 체력 +30 |
| 시간의 부적 | 150금 + 포자 결정 1 | 회피 재사용 -30%, 감속장 재사용 -3초 |
| 송곳니 목걸이 | 200금 + 우두머리 송곳니 1 | 빈틈 피해 1.5배 → 2.0배 |
| 무기 강화 +1/+2/+3 | 80/140/220금 + 철 조각 1 | 공격력 +15%씩 |

| 재료 | 판매가 | 획득 |
|---|---|---|
| 늑대 가죽 | 15 | 근교 숲, 늑대 굴 |
| 철 조각 | 20 | 바람 능선, 심층 습지 |
| 포자 결정 | 25 | 포자 습지, 심층 습지 |
| 우두머리 송곳니 | 60 | 늑대 굴·심층 습지 정예 처치 |

## 7. 하루와 지역
- 하루 5시간. 출격 비용은 **선택 전에 표시**되고 출발 시 차감된다. 전투가 오래 걸려도 추가 차감 없음.
- 조우 승리 후 "더 깊이 탐험(+1시간)"을 선택하면 같은 지역의 강화 조우(적 수 +1, 마지막에 정예)를 한 번 더 하고 보상 1.5배.
- **휴식**: 1시간 → 체력 완전 회복.
- **귀환**: 전리품을 거점에 반영. 시간은 남아 있으면 계속 출격 가능.
- **하루 종료**: 남은 시간을 버리고 다음 날. 체력 완전 회복, 시간 5.
- **보스**: 7일차 시작 시 도래. 보스전은 **첫 버전에 없음** — 도래 화면에서 사실대로 표시하고 새 회차 시작만 제공(추적표 R-BOSS-01).

| 지역 | 시간 | 위험 | 목적 | 구성 | 보상 |
|---|---|---|---|---|---|
| 근교 숲 | 1 | ★ | 전멸 | 늑대 2 / 3 / 4 | 금 30~45, 가죽 1~2 |
| 바람 능선 | 1 | ★★ | 전멸 | 궁수 2 / 궁수2+늑대2 / 궁수3+늑대2 | 금 35~50, 철 1~2 |
| 포자 습지 | 2 | ★★ | 전멸 | 포자1+늑대1 / 포자2+늑대2 / 포자2+궁수2 | 금 50~70, 포자 1~2 |
| 늑대 굴 | 2 | ★★★ | 정예 처치 | 늑대3 / 늑대3+궁수2 / 우두머리+늑대2 | 금 70~100, 가죽 2~3, 송곳니 |
| 심층 습지 | 3 | ★★★ | 정예 처치 | 포자2+궁수2 / 늑대4+포자1 / 우두머리+포자2+궁수2 | 금 100~140, 포자 2~3, 철 2, 송곳니 |

- 전장 목표: 2번째 웨이브에 **보급 상자**가 가장자리에 나타나며 닿으면 금화 +15~25. 이동할 이유를 만든다.

## 8. 조우 진행
1. 웨이브 1 등장(화면 가장자리에서 진입, 0.6초 등장 경고 표시).
2. 웨이브의 적이 전부 죽으면 1.2초 뒤 다음 웨이브.
3. 목적 달성(전멸 또는 정예 처치) → "조우 승리" → 보상 집계 → 증강 선택 → 더 깊이/귀환 선택.

## 9. 패배·회차 종료·재시작
- **패배**(체력 0): 이번 출격의 전리품을 잃고 거점으로 귀환. 남은 시간이 있으면 1시간 차감(부상 치료). 체력 30%로 복귀. 증강·장비는 유지.
- **회차 종료**: 7일차 도래 화면. 새 회차 시작만 가능.
- **재시작**: 제목 화면의 "새 회차"는 저장을 덮어쓴다(확인 창 있음).

## 10. 저장
- 거점의 모든 변화 뒤 자동 저장(`localStorage`). "저장 후 종료"로 제목 화면 복귀.
- 전투 도중 창을 닫으면 그 출격은 사라진다(비용은 이미 지불됨). 거점 상태로 복구된다.

## 11. 화면 구성 원칙
- 전투: 상단 좌 체력/보호막, 하단 중앙 회피·특수기 슬롯(재사용 원형 게이지), 상단 우 목적·웨이브, 하단 우 조작키.
- 그리기 순서: 바닥 지역 → 내 공격 잔상(반투명) → 적/플레이어 → **적 예고선(최상단)** → 투사체 → 피해 숫자 → HUD. 내 이펙트가 예고를 덮지 않는다.
- 상태 표시: 냉기(눈 결정), 표식(과녁), 빈틈(별), 감속(시계). 색 + 형태.
- 거점: 남은 시간·날짜·보스 도래·체력·금화·재료·목표 장비 부족분이 첫 화면에 보인다.

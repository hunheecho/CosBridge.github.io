# 예언의 시간표: 액션 프로토타입 — 게임 명세 (현재 규칙)

이 문서는 **현재 코드가 실제로 따르는 규칙**을 적는다. 미확정 수치는 `docs/ASSUMPTIONS.md`에 임시값으로 표시하고, 전체 기획과 개발 순서는 `docs/TRACEABILITY.md`에서 추적한다.

## 0. 한 문장 요약
마검사가 보스가 도래하기 전 며칠 동안 하루 5시간을 배분해 지역으로 출격하고, **짧은 실시간 전투**에서 적의 예고를 읽어 대응하며, 증강·장비로 공격 형태를 바꿔 다음 전투를 다르게 푼다.

## 1. 시간 구조 (네 층위)
| 층위 | 정의 | 유지되는 것 | 초기화되는 것 |
|---|---|---|---|
| 개별 전투(조우) | 한 지역에서의 40~120초 실시간 전투 | 체력, 증강, 장비, 획득물 | 보호막, 특수기 재사용, 전장 효과(불길·구름·표식) |
| 하루 | 5시간 예산. 출격·휴식으로 소모 | 위와 동일 + 금화·재료 | 남은 시간(5로), 체력(가득) |
| 회차 | 1일차부터 7일차 보스전(승리 또는 계속 재도전)까지 | 레벨·경험치·무기·증강·기술·패시브·장비·금화·재료·날짜 | 새 회차 시작 시 전부 |
| 회차 간 영구 해금 | **첫 버전에 없음**(기획 보류, 추적표 R-META-01) | — | — |

## 2. 조작 (화면 하단에 상시 표시)
| 입력 | 동작 |
|---|---|
| W A S D / 방향키 | 이동 |
| Space | 회피(구르기) |
| Q | 감속장 |
| E | 선택 수동 기술(레벨업에서 습득) |
| Esc | 일시정지(전투 정지) |
| Enter / 클릭 | 메뉴 확인 |
| F3 | 디버그 오버레이(개발용, 기본 꺼짐) |

- 마우스 조준 없음. 회피 방향은 현재 이동 입력, 없으면 마지막 바라보는 방향.
- 자동 공격은 어떤 입력도 막지 않는다. 회피 중에도 자동 공격은 계속된다.
- 선택 화면·일시정지·포커스 이탈(창 전환) 시 시뮬레이션은 완전히 멈춘다.
- **정지 중 전투 입력은 버린다**: 일시정지·조작법 오버레이 중에 누른 이동·회피·특수기 키는 누적되지 않고, 정지·재개 양쪽에서 남은 눌림/단발 입력을 비운다. 재개 후에는 키를 다시 눌러야 한다(`src/input.js`).

## 3. 플레이어
- 체력 100(장비로 증가), 이동 속도 220px/s, 판정 반지름 14.
- **보호막**은 체력과 별도 게이지(청록). 피해는 보호막 → 체력 순으로 적용.
- **피격 보호**: 피해를 받으면 0.6초 동안 추가 타격 무효(점멸). 같은 프레임에 겹친 여러 적의 공격은 최대 1회만 적용된다.
- **지역 피해(포자 구름 등)**: 0.5초마다 1틱. 겹친 지역이 여러 개여도 틱당 가장 큰 피해 1회만. 피격 보호를 무시하지만 회피 무적은 존중한다.
- **패배**: 체력 0 → 조우 즉시 종료(§9).

### 3.1 자동 공격 규칙(확정 기본값)
- **발동 조건**: 사거리 안에 적이 있을 때만 주기마다 발동. 빈 허공에 휘두르지 않는다.
- **대상**: (1) 사냥꾼의 표식 대상이 사거리 안이면 그 대상, (2) 아니면 가장 가까운 적.
- **방향**: 발동 순간 대상의 위치. 발동 후 방향은 바뀌지 않는다.
- **판정**: 발동 프레임에 1회. 한 번의 검격은 한 적에게 최대 1회 피해.
- **표시**: 부채꼴/직선 잔상이 0.15초 남고, 사거리는 플레이어 주변 옅은 원으로 상시 표시.

### 3.2 공격 형태(무기)
| 형태 | 획득 | 판정 | 특징 |
|---|---|---|---|
| 검격(기본검) | 시작 | 반지름 95, 각도 110° 부채꼴 | 정면 다수 |
| 관통 검격(관통검) | 대장간 제작 | 길이 230, 폭 44 직선, 관통 | 일렬로 모인 적 처리 |
| 회전 검격 | 증강 | 3번째 검격마다 360° 반지름 110 | 둘러싼 적 처리, 넉백 큼 |

무기 효과는 "형태", 증강은 "성능·행동·결합"으로 구분한다.

### 3.3 회피
- 지속 0.26초, 이동 150px, **전 구간 무적**. 종료 후 재사용 0.9초.
- **회피의 역할**: 위험에서 벗어나기, 공격하기 좋은 위치로 이동하기, 돌진 경로에서 빠져나오기. 회피 무적 구간에 적의 공격이 실제로 닿았다면 "회피!"가 뜨지만 이는 피드백일 뿐이며 **어떤 성장 보상과도 연결되지 않는다**(사용자 결정: 정밀 회피 성공 중심 성장은 채택하지 않음). 통계는 내부 디버그용으로만 남긴다.

### 3.4 특수기: 감속장(수동 슬롯 1)
- Q. 플레이어 위치에 반지름 150 원, 3.0초 지속. 안의 적·투사체는 속도와 준비 시간이 40%로 느려진다.
- 재사용 14초(장비로 감소). 조우 시작 시 즉시 사용 가능. 재사용이 준비돼도 자동 발동하지 않는다.
- 감속장이 활성 중일 때 다시 시전하면(시간 저축으로 재사용이 0이 된 경우) 이전 감속장을 먼저 정상 종료(정지된 칼날 폭발 포함)한 뒤 새 감속장을 만든다.
- 수동 슬롯은 1개. 이후 기술이 늘어도 슬롯 수는 늘리지 않고 교체한다(추적표 R-CTRL-03).

## 4. 적
공통: 회복 중(빈틈) 상태의 적은 받는 피해 1.5배, 머리 위에 어지러움 표시. 적끼리는 서로 밀어내 완전히 겹치지 않는다. 적은 서로 접촉해도 플레이어에게 **접촉 피해를 주지 않는다**. 모든 피해는 예고된 공격과 지역에서만 나온다.

### 4.1 늑대 — 역할: 돌진 습격
| 단계 | 시간 | 표시 | 규칙 |
|---|---|---|---|
| 접근 | — | 걷기 | 150px/s로 접근, 170px 안이면 준비 |
| 준비(웅크림) | 0.6초 | 몸이 낮아지고 **붉은 화살표**가 플레이어를 따라 회전 | 이 동안은 방향 추적 |
| 확정 | 0.15초 | 화살표 굵어지고 밝게 점멸 | **방향 고정**. 이후 절대 바꾸지 않음 |
| 돌진 | 0.32초 | 잔상 | 800px/s 직진. 벽에서 정지. 접촉 시 12 피해(1회) |
| 빈틈 | 0.9초 | 어지러움 표시 | 이동 불가, 피해 1.5배 |
- 기본 대응: 확정 신호를 보고 **옆으로** 이동/회피.
- 빌드 대응: 잔불 걸음(회피 자리에 불길 → 돌진 경로가 불길 통과), 관통(일렬 돌진 후 정렬된 늑대 처리).
- 조합: 궁수와 같이 있으면 돌진을 피한 위치가 화살 궤적과 겹치는지 판단해야 한다.

### 4.2 늑대 우두머리(정예) — 역할: 정예 처치 목표

- 기본 대응: 선을 보고 옆으로, 접근해서 우선 처치(체력 22). 빌드: 표식(자동 우선 공격), 관통(멀리서도 직선 판정).

### 4.5 기획에 있으나 첫 구현에 없는 적
멧돼지(장애물 충돌 경직), 주술사(강화·회복), 방패병(정면 방어). 추적표 R-ENEMY-05~07.

## 5. 성장 (v0.5 개편)
### 5.1 구조
| 슬롯 | 규칙 |
|---|---|
| 무기 | 장착 3개(시작 1 + 전투 중 획득 2). 모두 자동 공격. 최대 5레벨. 전용 방식 증강 최대 2개. 시작·추가 무기의 성능·한도 동일 |
| 공통 증강 | 별도 3슬롯. 하나를 얻으면 조건에 맞는 모든 장착 무기·기술에 적용, 나중에 얻은 무기에도 자동 적용. 같은 증강의 단계 상승은 슬롯을 쓰지 않음 |
| 수동 기술 | Q 감속장(기본), E 선택 기술 1개. 각 최대 3레벨, 방식 변형 각 1개 |
| 패시브 | 서로 다른 4종, 각 최대 3레벨 |
| 회피 | Space 기본. 성공 판정과 성장 보상을 연결하지 않음 |
| 보스 희귀 보상 | 별도 보관. 현재 보스 목록의 마지막 보스 뒤에는 제시하지 않음 |

### 5.2 캐릭터 레벨과 경험치
- 캐릭터 레벨업 = 성장 카드 3택 1회. 무기 레벨은 그 3택에서 그 무기의 강화 카드를 골랐을 때만 오른다.
- 경험치는 적이 죽는 즉시 획득한다. 바닥 구슬·획득 반경·자석 없음. 처치 원인(직접·지속·소환·지뢰·파편·폭발) 무관. 같은 적 1회, 동시 처치 합산, 여러 레벨이 한 번에 오르면 선택 횟수를 그만큼 누적(`pendingLevelUps`).
- 필요 경험치 = 14 + 4×(레벨−1). 경험치 값: 늑대 6, 궁수 7, 포자 8, 우두머리 30, 소환 늑대 6, 보스 0.
- 조우 승리 시 지역 경험치 보너스(숲 10 / 능선 12 / 습지 16 / 굴 20 / 심층 28, 더 깊이 ×1.5). 기존 "조우 승리마다 증강 3택"은 이 보너스와 레벨업으로 통합했다. 더 깊이 탐험 승리 시에는 지역 태그 후보만으로 구성된 3택(지역 보상)을 1회 제공한다.
- 레벨·경험치는 출격·휴식·날짜 사이에 유지되고 새 회차에서 초기화된다. 보스 재도전은 입장 시점의 성장(레벨·경험치·선택)으로 복구되어 소환 경험치 누적 악용을 막는다.
- 레벨업 선택 중 전투·게임 시간이 멈추고 입력이 차단된다(선택 중 누른 Q·E·Space는 재개 때 발동하지 않음). 사망·보스 처치와 동시에 발생하면 결과 화면이 먼저 나오고 선택은 미처리로 저장되어 다음 화면(보상·거점)에서 처리한다.

### 5.3 무기 레벨
1레벨부터 고유 방식. 레벨 배율 100/120/140/160/180%(기본 피해에 대한 누적 배율). 피해 = 기본 × 레벨 배율 × 대장간 강화(+15%/단계, 세 무기 공통) × 무기 숙련(+10%/레벨) — 각각 한 번씩. 추가 무기는 자기 레벨을 쓴다.

첫 검증 시작 무기: 검·관통창·회전 칼날. 나머지 시작 후보는 시작 화면의 검증 메뉴. 기존 관통검 데이터·소유·저장은 관통창으로 이어진다(상점의 "관통검 제작"은 빈 무기 슬롯에 관통창을 추가).

- 조우 승리 후 "더 깊이 탐험(+1시간)"을 선택하면 같은 지역의 강화 조우(적 수 +1, 마지막에 정예)를 한 번 더 하고 보상 1.5배.

- **귀환**: 전리품을 거점에 반영. 시간은 남아 있으면 계속 출격 가능.
- **하루 종료**: 남은 시간을 버리고 다음 날. 체력 완전 회복, 시간 5.
- **보스**: 7일차 시작 시 도래(`phase = boss_prep`). 7일차에는 일반 출격이 없고 최종 준비(구매·강화·판매·장비 교체) 뒤 보스전에 들어간다(§13).

## 8. 조우 진행
1. 웨이브 1 등장(화면 가장자리에서 진입, 0.6초 등장 경고 표시).
2. 웨이브의 적이 전부 죽으면 1.2초 뒤 다음 웨이브.
3. 목적 달성(전멸 또는 정예 처치) → "조우 승리" → 보상 집계 → 증강 선택 → 더 깊이/귀환 선택.

## 9. 패배·회차 종료·재시작
- **패배**(체력 0): 이번 출격의 전리품을 잃고 거점으로 귀환. 남은 시간이 있으면 1시간 차감(부상 치료). 체력 30%로 복귀. 증강·장비는 유지.
- **보스 패배**: 준비 기간의 성과를 잃지 않는다. 같은 장비·증강으로 즉시 재도전(추가 비용 없음, 재도전 횟수 기록). 재도전은 같은 보스전 시드·지형.
- **보스 승리**: 회차 결과 화면. 이번 빌드로 다시 도전 / 새 회차 / 제목. 새 회차는 자동 시작하지 않고 기록도 자동 삭제하지 않는다.
- **재시작**: 제목 화면의 "새 회차"는 저장을 덮어쓴다(확인 창 있음).

## 10. 저장
- 거점의 모든 변화 뒤 자동 저장(`localStorage`). "저장 후 종료"로 제목 화면 복귀.
- **출격 시작·더 깊이 탐험 시작·증강 선택 직후에도 저장**한다. 전투 도중 창을 닫으면 그 출격의 전리품은 사라지지만 비용(시간)은 지불된 상태, 이미 고른 증강은 유지된 상태로 거점에 복구된다.
- **보스 직전 저장**: "보스에게 간다"를 누른 시점의 상태를 저장한다. 전투 중 창을 닫으면 전투 상태를 복원하지 않고 최종 준비에서 다시 시작한다(재화·장비 복제 없음).
- **저장 버전 3**(v0.5): `growth`(레벨·경험치·미처리 선택·보류 제시·무기·공통·기술·패시브·보스 보상·레거시). v2 이하는 불러올 때 `Growth.migrateFromLegacy`로 매핑: 관통검 소유 → 관통창, spin → 회전 칼날, sharp → 무기 숙련, quick → 가속, wide/ember/frost/flare/echo/saving/stasis → 공통, barrier → 수호 결계(E) + 레거시 보호막, mark → 레거시 표식(신규 제시 없음). 공통이 3개를 넘으면 삭제하지 않고 거점의 이행 화면에서 3개를 고른다.
- **저장 버전 2**: `phase`(prep / boss_prep / cleared), `bossRetries`, `bossClear`(첫 처치 기록), `lastBossClear`. v1 저장은 불러올 때 마이그레이션한다: 7일차 `ended=true` → `boss_prep`, 그 외 → `prep`. 이전 저장을 삭제하지 않는다. 처치 기록은 회차와 별도 키(`prophecy_action_records_v1`)에 첫 처치와 최근 20회를 보관하며 새 회차로 지워지지 않는다.
- `?scenario=` 시험 전투는 저장하지 않는다. 시험 종료 후 제목·새 회차·계속하기로 나가면 시험 모드가 해제되고 URL의 시험 파라미터도 지운다.

## 11. 화면 구성 원칙
- 전투: 상단 좌 체력/보호막, 하단 중앙 회피·특수기 슬롯(재사용 원형 게이지), 상단 우 목적·웨이브, 하단 우 조작키.
- 그리기 순서: 바닥 지역 → 내 공격 잔상(반투명) → 적/플레이어 → **적 예고선(최상단)** → 투사체 → 피해 숫자 → HUD. 내 이펙트가 예고를 덮지 않는다.
- 상태 표시: 냉기(눈 결정), 표식(과녁), 빈틈(별), 감속(시계). 색 + 형태.
- 거점: 남은 시간·날짜·보스 도래·체력·금화·재료·목표 장비 부족분이 첫 화면에 보인다.

## 12. 시각 표현 (숲 전장, v0.2)
- 모든 그래픽은 코드로 그린 벡터 도형이며 외부 자산이 없다. 캐릭터 시각 배율 1.25(판정 반지름은 그대로).
- **마검사**: 머리·머리카락·눈, 갑옷 몸통, 망토, 두 다리(걷기 시 교차), 앞팔에 검(손잡이·날밑·날). 바라보는 방향으로 좌우 반전. 대기(검을 앞아래로), 걷기(다리 교차·상하 흔들림·망토 펄럭임), 검 휘두르기(`swingT` 0.18초 동안 검이 -80°→+80° 호를 그림, 판정과 같은 프레임에 시작), 관통 찌르기(검이 앞으로 뻗음), 회전(검 360°), 회피(몸이 한 바퀴 구르고 잔상), 피격(붉게 물들고 좌우 흔들림, 붉은 링).

### 13.3 지형 규칙(모든 전투 공통, 장애물이 있는 전장에서 적용)
| 대상 | 규칙 |
|---|---|
| 지상 이동 | 플레이어·보스·늑대는 장애물을 통과하지 않는다. 이동 구간 전체를 스윕 검사하고, 걷기는 표면을 따라 미끄러진다. 회피·돌진·넉백은 처음 닿는 지점에서 멈춘다(dt 무관) |
| 돌진 | 벽·장애물에 닿으면 접촉 위치에서 종료 → 정상 빈틈. 물기 판정은 실제로 이동한 구간에만 적용(장애물 뒤 관통 없음). 예고 통로와 도착 지점은 같은 계산(`Boss.dashPath`)으로 실제 종료 위치를 반영 |
| 직접 공격 | 검격·관통·회전·메아리·휩쓸기는 공격 시작점과 대상 사이에 장애물이 있으면 맞지 않는다. 관통 검광은 장애물에서 멈춘다 |
| 투사체 | 얼음 파편·화살은 같은 이동 구간에서 장애물과 개체 중 먼저 만난 쪽에 적용된다 |
| 마법·바닥 효과 | 감속장은 장애물 너머에도 적용. 불길 틱·불꽃 파열·덮쳐찍기 지면 충격은 표시된 바닥 범위 그대로. 정지된 칼날은 이미 쌓인 흔적의 폭발이라 대상이 장애물 뒤로 가도 터진다 |
| 불길 생성 | 회피 경로의 불길 조각이 장애물 안쪽이면 그 조각은 생략한다(플레이어 위치는 항상 유효해 보통 발생하지 않음) |
| 도약 | 덮쳐찍기는 장애물 위를 넘는다. 착지점은 보스 몸이 들어가는 빈 공간으로 보정해 먼저 예고하고, 확정 뒤 바꾸지 않는다 |
| 경로 탐색 | 보스·늑대는 진행 방향의 장애물을 접선 방향으로 돌아간다(선택한 쪽을 0.8초 유지해 떨림 방지). 반지름을 포함해 계산 |
| 자동 공격 대상 | 가려진 대상은 대상 후보에서 제외되므로 허공 공격이 없다. 표식 대상이 가려지면 공격 가능한 다른 적을 친다 |
| 가독성 | 나무 충돌은 줄기·밑동 링. 수관은 개체 위·예고선 아래에 그리며 개체가 가까우면 투명(0.32). 돌의 외형 = 충돌 원 |

전환: 체력선을 넘긴 순간 회복 구슬을 생성하고, 진행 중 공격이 끝난 뒤 포효(0.9초, 피격 가능)로 새 단계를 적용한다. 같은 전환 이벤트는 한 번만. 한 번에 두 선을 넘기면 구슬 2개, 단계는 3으로.

### 13.6 감속장·냉기와 보스
감속장은 보스의 접근·준비·확정 대기·돌진·도약·빈틈 진행을 모두 40%로 늦춘다(플레이어 공격은 그대로). 확정된 방향·착지점은 감속으로 다시 추적되지 않는다. 이동 속도: 냉기만 60%, 감속장 40%, 둘 다 40%(더 강한 쪽, 곱하지 않음). 준비·빈틈 진행 감소는 감속장만 담당. 이 규칙은 일반 적에도 같다(v0.4에서 곱셈 → 최소값으로 변경).

### 13.7 회복 구슬
70%·35% 첫 통과 시 각 1개. 회복량 = floor(최대 체력 × 0.15). 접촉 획득, 시간 경과로 사라지지 않음, 최대치 초과 없음, 중복 획득 없음. 배치: 보스 주변 반지름 170의 24방향 중 유효 바닥이면서 보스 몸(+30)과 현재 위험 예고(돌진 통로·휩쓸기 부채꼴·착지 원) 밖인 지점 가운데 플레이어에게 가장 가까운 곳. 없으면 플레이어 근처의 유효 위치.

### 13.8 방벽·표식·시간 저축
파열 방벽: 범위 안 늑대는 기존 넉백. 보스는 진행 중 공격을 끊고 1.0초 비틀거림(빈틈 배율, 밀지 않음). 도약 중이면 착지 후 적용. 이미 적용된 피해는 취소하지 않는다. 표식 우선순위: 보스 > 우두머리 > 궁수 > 포자 > 늑대. 시간 저축은 감속장 안의 소환 늑대 처치에도 적용된다.

### 13.9 승리·패배
보스 체력 0: 즉시 모든 적·위험·피해 정지, 2.4초 쓰러짐 뒤 결과 화면. 같은 단계에서 플레이어도 죽으면 승리 우선. 결과 화면: 전투 시간·재도전 횟수·무기/강화·장신구·방어구·증강·감속장 사용 횟수·보스에게 준 총피해(실제 체력 감소 기준, 늑대·과잉 피해 제외). 효과별 피해 통계는 후속.

### 13.10 HUD·표현
상단 중앙 보스 이름·큰 체력바·70%·35% 눈금·현재 행동 문구("사냥 돌진 준비", "연속 돌진 1/2", "무리 소환", "빈틈!", "감속 중")·소환 늑대 수. 보스는 늑대 표현을 확장한 벡터: 큰 어깨, 검은 가시갈기(세우면 길어짐), 부러진 송곳니, 흉터, 붉은 눈. 자세: 낮춤(돌진), 고개 옆으로(휩쓸기), 고개 들고 갈기 세움(소환·포효), 움츠리고 앞발 모음(덮쳐찍기), 고개 낮추고 숨 고르기(빈틈). 소리: 울부짖기, 포효, 착지, 휩쓸기, 확정 경고, 구슬.

# 인수인계 (현재 상태와 다음 작업만)

## 현재 상태 (v0.2.0)
- **숲 전장 시각 표현 완료(1차)**: 코드로 그린 마검사(7자세)와 늑대(6동작+사망), 숲 바닥·풀·낙엽·돌·흙길·나무 경계, 검격·피격·처치·감속장 효과와 소리. 물기 판정 프레임 = 턱 닫힘 프레임. 자세표 `docs/screenshots/pose_*.png`, 녹화 `docs/video/combat_forest.webm`(21초 실제 전투), 8초 클립 `combat_forest_clip.webm`.
- 첫 플레이 가능한 한 바퀴(A~H)가 연결되어 있다: 거점 → 지역 선택 → 실시간 전투 → 보상·증강 → 더 깊이/귀환 → 상점·대장간 구매·장착 → 재출격 → 하루 종료 → 7일차 보스 도래(보스전 미구현, 정직 표시).
- 자동 검증: `node --test test/*.test.js` 32개 통과. `tools/playthrough.js` 봇이 한 바퀴를 오류 없이 완주(관통검 제작, 저장·재실행 동일, 관통 검격 관측).
- 화면 검증: 헤드리스 Chromium 캡처(`tools/shots.js`)로 거점·지도·상점·전투·보상·일시정지·작은 창을 확인. **실제 Windows·소리·사람의 조작감은 미확인.**
- 콘텐츠: 적 4종(늑대, 우두머리, 궁수, 포자 괴물), 지역 5곳, 증강 12종, 장비 5종(강화 3단계 포함), 공격 형태 3종.

## 알려진 문제·미확인
- 봇 기준으로 근교 숲·능선이 쉽고(피해 0~22), 1일차에 관통검을 살 수 있다. 사람 플레이로 난도·가격을 조정해야 한다.
- 궁수·포자 괴물은 아직 간이 표현이다.
- 관통검의 사거리 표시는 원(반지름 230)이라 실제 직선 판정과 형태가 다르다.
- 헤드리스에서 Google Fonts 요청이 프록시로 막혀 콘솔 오류가 난다(게임 동작 무관, 시스템 폰트로 대체).
- 아슬아슬한 회피는 "회피 무적 중 실제로 닿은 공격"으로 판정되므로, 옆으로 걸어 피하면 기록되지 않는다(의도).

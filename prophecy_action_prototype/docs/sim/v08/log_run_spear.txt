# 회차 시뮬레이션 [S_spear] (v0.8.0, 봇 balanced, 배치 classic, 난이도 base, 시작 무기 spear, 회차 구조 trio, 처치 경험치 ×1, 지역 경험치 ×1, 보스 체력 base)

전략 3종 × 시드 1,2,3,4,5 × 경험치 곡선 v06. 봇 결과는 정책 비교용이며 사람의 체감 플레이타임·재미와 다르다.

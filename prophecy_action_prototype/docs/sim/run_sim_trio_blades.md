# 회차 시뮬레이션 (v0.7.0, 봇 balanced, 배치 classic, 난이도 base, 시작 무기 blades, 회차 구조 trio)

전략 3종 × 시드 1,2,3 × 경험치 곡선 v06. 봇 결과는 정책 비교용이며 사람의 체감 플레이타임·재미와 다르다.

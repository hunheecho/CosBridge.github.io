# 회차 시뮬레이션 [T03_blades] (v0.8.0, 봇 balanced, 배치 classic, 난이도 base, 시작 무기 blades, 회차 구조 trio, 처치 경험치 ×1, 지역 경험치 ×1, 보스 체력 base)

전략 3종 × 시드 1,2,3,4,5 × 경험치 곡선 v06. 봇 결과는 정책 비교용이며 사람의 체감 플레이타임·재미와 다르다.

시간 계정(검수 수정 후): 시뮬레이션된 시간 = 전투 + 보스(고정 단계 시계). 가정한 메뉴 시간 = 카드 1장 6초(전투 중 레벨업·지역 3택 포함, 실제 발생 시점에 기록) + 조우 전후 화면 25초 + 하루 종료 10초 + 휴식 5초. 합계는 보스전까지 포함해 마지막에 한 번만 더한다. 시간 초과(봇이 조우 240초/보스 300초 안에 못 끝냄)는 패배와 별도 열. 조우 생성·정산·3택은 게임과 같은 PA.Flow 경로(더 깊이 지역 3택 포함).

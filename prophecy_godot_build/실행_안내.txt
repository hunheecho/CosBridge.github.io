예언의 시간표(가칭) — Godot 이식 godot-0.4.0 (Windows 플레이 빌드)

1. ZIP을 아무 폴더에 풀고 prophecy_godot.exe 를 실행합니다. Godot 설치가 필요 없습니다.
   (Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행". 서명되지 않은 빌드입니다.)
2. 제목 화면: [새 회차] → 시작 기술(검/관통창/회전 칼날) → 거점. [계속하기]는 저장된 회차(user 폴더 prophecy_save_v1.json).
   [검증 메뉴]에 0.3.1 기준 전투(사람/봇), 시작 기술 첫 전투 비교, 관문 빌드 보스전, 봇 회차 데모가 있습니다.
3. 조작: WASD/방향키 이동, Space 회피(짧게/길게 눌러 거리 70~150, 재사용 1.5초), Q 감속장, E 수동 기술(습득 후),
   자동 공격(보유 자동기술이 사거리 안의 적에게 자동 발동), Esc 일시정지/메뉴 닫기, Enter 기본 버튼, F3 검증 패널.
   밑줄 친 용어는 마우스를 올리면 설명, 클릭하면 고정(전투 중 고정 시 일시정지).
4. 회차: 7일·하루 5칸. 거점에서 오늘의 장소 카드 2장(시간대에 따라 편성·사건·보상이 달라짐) → 전투(전멸/사냥/제단/봉인/구조) →
   승리 뒤 더 깊이(1회) 또는 귀환 → 상점·장비·대장간·휴식 → 하루 종료. 3·5·7일차는 관문 보스(패배 시 입장 시점으로 복구·재도전).
5. 잠정값(사용자 확인 전): 일반 적 개체 수는 HTML 편성의 5배(동시 최대 12, 종류별 상한), 보스 체력 2400/5000/7000, 창 근접 약화.
   자세한 규칙과 근거: 저장소 prophecy_godot/docs/ (RULES.md, ASSUMPTIONS.md, FORMATION_TABLE.md, PORT_NOTES.md §12).

빌드 정보: Godot 4.7.2-stable 공식 Windows 내보내기 템플릿(x86_64, release, pck 내장)으로 Windows 10에서 내보냈습니다.
실행 확인: 같은 PC에서 봇 자동 진행(PROPHECY_UI_SMOKE)으로 새 회차→관문까지 실행 확인. 사람 키보드 플레이는 미확인.
실행이 안 되면 prophecy_godot 폴더를 Godot 4.7.2 편집기로 열어 F5로 실행하세요.

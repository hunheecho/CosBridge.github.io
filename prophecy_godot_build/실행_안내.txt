예언의 시간표 — Godot 첫 전투 (Windows 플레이 빌드)

1. ZIP을 아무 폴더에 풀고 prophecy_first_fight.exe 를 실행합니다. Godot 설치가 필요 없습니다.
   (Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행". 서명되지 않은 빌드입니다.)
2. 시작 화면: Enter 또는 [전투 시작]. [봇 조작으로 보기]는 같은 규칙으로 봇이 싸우는 모습.
3. 조작: WASD/방향키 이동, Space 회피, Q 감속장, 자동 공격(검격 Lv1), Esc 일시정지/재개, F3 검증 패널.
4. 승리(예정된 늑대 5마리 전멸)·패배(체력 0) 뒤 Enter로 같은 조건(같은 시드) 재시작.

빌드 정보: Godot 4.7.2-stable 공식 Windows 내보내기 템플릿(x86_64, release, pck 내장)으로 Linux에서 내보냈습니다.
Windows 실기 실행은 미확인입니다. 실행이 안 되면 prophecy_godot 폴더를 Godot 4.7.2 편집기로 열어 F5로 실행하세요.

예언의 시간표(가칭) — Godot 이식 godot-0.7.0 (Windows 플레이 빌드)

1. ZIP을 아무 폴더에 풀고 prophecy_godot.exe 를 실행합니다. Godot 설치가 필요 없습니다.
   (Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행". 서명되지 않은 빌드입니다.)
2. 제목 화면: [새 회차] → 시작 기술(검/관통창/회전 칼날) → 거점. [계속하기]는 저장된 회차(user 폴더 prophecy_save_v1.json).
   [검증 메뉴]에 0.3.1 기준 전투(사람/봇), 시작 기술 첫 전투 비교, 관문 빌드 보스전, 봇 회차 데모가 있습니다.
3. 조작: WASD/방향키 이동, Space 회피(짧게/길게 눌러 거리 70~150, 재사용 1.5초), Q 감속장, E 수동 기술(습득 후),
   자동 공격(보유 자동기술이 사거리 안의 적에게 자동 발동), Esc 일시정지/메뉴 닫기, Enter 기본 버튼, F3 검증 패널.
   밑줄 친 용어는 마우스를 올리면 설명, 클릭하면 고정(전투 중 고정 시 일시정지).
4. 회차(본편): 10일·3막·하루 5칸. 막마다 테마 1개가 시드로 정해집니다(1막 사냥 숲/버려진 요새/포자 정원, 2막 붉은 의식터/무너지는 광산/얼어붙은 협곡,
   3막 시간의 심연/피의 사냥터/뒤틀린 성채 = 27경로). 거점에서 오늘의 장소 카드 2장(시간대에 따라 편성·사건·보상이 달라짐) → 전투 →
   승리 뒤 더 깊이(1회) 또는 귀환 → 상점·장비·대장간·휴식 → 하루 종료. 4·7·10일차는 관문 보스(테마 전용 보스 9종 중 경로의 것, 패배 시 입장 시점으로 복구·재도전).
   관문 준비 화면에 다음 막 미리보기. 검증 메뉴에서 경로를 직접 지정할 수 있습니다. 옛 7일 저장은 그 규칙으로 이어집니다.
   완주 뒤 [현재 빌드로 계속(무한 모드)]: 구간(전투 3 + 구간 보스)마다 적·보스 체력이 오르고 하위 등급이 빠집니다. 무한에서 져도 완주 기록은 유지됩니다.
   영구 성장 Lv15 이후 [정복자] 포인트(공격/최대 체력/이동)를 출발 전에 배분합니다(시험값).
5. 잠정값(사용자 확인 전): 일반 적 개체 수는 HTML 편성의 5배(동시 최대 12, 종류별 상한; 검증 메뉴에서 역할별 세트와 비교 가능), 보스 체력 2400/5000/7000, 창 근접 약화.
   첫 관문 승리 뒤 '붉은 달'(붉은 개체), 두 번째 관문 뒤 상위 변이가 나옵니다(체력·피해 배율은 시험값). 회차마다 특징 1줄, 카드마다 편성 이름, 사건 '강적의 흔적'(거절 가능).
   제목 화면 [영구 성장]: 별도 시험 프로필(legacy = 전부 공개 / trial = 해금 초안). 봇·검증 메뉴 진행은 영구 기록에 반영되지 않습니다.
   터치 화면이면 가로 터치 조작(왼쪽 스틱·오른쪽 회피/Q/E)이 켜집니다(PC에서는 PROPHECY_TOUCH=1로 시험). Android/iOS 실기 검증은 하지 않았습니다.
   자세한 규칙과 근거: 저장소 prophecy_godot/docs/ (RULES.md, ASSUMPTIONS.md, FORMATION_TABLE.md, PORT_NOTES.md §12).

6. 사람 플레이 입력 기록(선택): 제목 화면 [검증 메뉴]에서 "이번 전투 입력 기록" 체크 → 기준 전투(사람) 또는 새 회차 전투를 직접 플레이 →
   전투가 끝나면 사람 입력만 JSON으로 저장됩니다(봇 전투는 기록하지 않음, 업로드·전송 없음).
   저장 위치: %APPDATA%\Godot\app_userdata\예언의 시간표 — Godot 첫 전투\recordings\<시각>_<시나리오>.json
   (탐색기 주소창에 %APPDATA%\Godot\app_userdata 를 붙여 넣으면 됩니다.) 기록 5~10회가 봇 실력 보정의 다음 입력이며, 파일을 개발자에게 전달하면 됩니다.

7. 이번 판(0.7.0)에서 달라진 것 — 사람 플레이 피드백 반영. 아래 수치는 전부 시험값입니다.
   · 날짜가 지날수록 일반 전투의 적 수가 늘어납니다(1일차 25 → 9일차 70, 핵심 장소 75). 동시에 살아 있는 수는 막마다 12/15/18로 따로 제한합니다.
   · 적 등급이 교체됩니다. 1막 일반, 2막 일반+붉은 개체, 3막 붉은 개체+상위 변이. 붉은 개체는 3막에서 더 강해지지 않습니다.
   · 보스가 훨씬 자주 공격하고 가까이 붙어도 안전하지 않습니다(가시갈기는 근거리 연계·옆 뛰기·도약 후 추격 추가).
   · 지원 적(궁수·주술사·포자)은 근접 적과 함께 나옵니다. 포자만 나오는 전투는 없습니다.
   · 새로 얻는 금화가 약 30% 줄었습니다(판매·환불은 그대로).
   · 하루 카드를 다 끝내도 시간이 남으면 같은 장소로 [일반 탐험 · 1칸]을 나갈 수 있습니다(임무 보상·사건은 다시 주지 않습니다).
   · 화면 아래에 자동기술 3칸과 각 기술에 붙은 개조 아이콘이 보입니다. 회피/Q/E는 오른쪽에 따로 있고 준비되면 테두리가 한 번 반짝입니다.
   · 제단 이름이 효과대로 바뀌었습니다(적 치유 제단 / 소환 제단 / 저주 제단).
   · 승인된 첫날 늑대 25마리 전투와 경험치 배율은 그대로입니다.

빌드 정보: Godot 4.7.2-stable 공식 Windows 내보내기 템플릿(x86_64, release, pck 내장)으로 Windows 10에서 내보냈습니다.
실행 확인: 같은 PC에서 봇 자동 진행(PROPHECY_UI_SMOKE)으로 새 회차→관문까지 실행 확인(0.6.0에서는 10일차 완주→무한 1구간까지). 사람 키보드 플레이는 미확인. 신규 보스 6종·무한·정복자 수치는 전부 시험값. 0.6.1 = 봇 관측·캐시 신뢰성 수정(게임 규칙 변경 없음).
실행이 안 되면 prophecy_godot 폴더를 Godot 4.7.2 편집기로 열어 F5로 실행하세요.

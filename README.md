# 예언의 시간표(가칭) — 저장소 안내

새 세션·새 협업자는 **`docs/PROJECT_CONTEXT.md`** 부터 읽는다. 읽기 순서·현재 초점·공식 문서 위치·운영 규칙이 거기 한 곳에 있다.

| 폴더 | 내용 |
|---|---|
| `docs/` | 공통 진입 문서(`PROJECT_CONTEXT.md`), 설계 변경 이력(`DESIGN_DECISIONS.md`), 과거 통합 초안·검수 증거 보관(`archives/`) |
| `prophecy_godot/` | Godot 4.7.2 첫 전투 프로젝트(현재 개발 방향). 규칙 `docs/RULES.md`, 실행 방법 `README.md` |
| `prophecy_godot_build/` | Godot 배포물 ZIP(프로젝트·Windows 빌드) |
| `prophecy_action_prototype/` | HTML v0.8.0 프로토타입(비교 기준선, 새 콘텐츠 추가 없음). 전체 설계 정본 `docs/GAME_SPEC.md`, 인수인계 `docs/HANDOFF.md` |

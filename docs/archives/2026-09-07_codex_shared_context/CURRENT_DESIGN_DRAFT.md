# 현재 설계 복원 초안

기록일 2026-09-07. 설계 기준이며 구현 완료 선언이 아니다.
기존 GAME_SPEC·ASSUMPTIONS에 병합 후 이 파일을 별도 정본으로 운영하지 않는다.
결정 배경은 DESIGN_DECISIONS.md의 D 번호 참조.

## 1. 전투와 조작 [D01–D04]

- 실시간 2D 액션, 자동 공격.
- WASD/방향키 이동, Space 회피, Q 감속장, E 수동기술.
- 자동기술 최대 3개, 각 Lv5·전용 개조 최대 2개.
- Q/E 각 최대 Lv3·변형 최대 1개. E 슬롯 1개.
- 공용 증강과 패시브는 별도. 기존 구현의 슬롯·최대치는 변경 합의가 없는 한 유지.
- 기본 공격력 성장은 기술 레벨, 방식 변화는 전용 개조 등으로 구분.
- 무기·신규 기술·수동 기술·공용 증강·패시브가 성장 후보에 포함.
- 피해와 예고 범위, 방향 확정, 현재 상태가 읽혀야 한다.
- 감속장을 활용한 대응은 유지. 회피 성공 보상 반복을 핵심 성장 축으로 사용하지 않는다.

## 2. 적·난이도·보스 [D05, D09, D12, D13]

- 행동이 다른 기본 몬스터 10~12종을 역할별로 편성. 색·체력 차이만으로 종류를 늘리지 않는다.
- 장소 재방문도 현재 날짜의 적 편성을 따른다.
- 날짜·지역·공개된 위험·심층으로 난이도 결정. 플레이어 DPS에 몰래 비례하지 않는다.
- 잡몹의 빠른 처치감과 주요 적의 패턴 실행 기회를 구분한다.
- 후반 편성은 이미 배운 돌진·지원·장판·후열·측면 위협을 조합.
- 기본 관문 3개: 3일차 가시갈기, 5일차 봉인 수호자, 7일차 예언을 먹는 자.
- 3·5일차 관문 승리 후 그날 준비 5칸 시작. 관문 자체는 5칸 밖.
- 첫 두 보스 뒤 희귀 보상 선택. 마지막 보스 뒤 런 종료.
- 표준 빌드의 제자리 맞공격과 대응 플레이에 차이가 있어야 한다.
- 준비 부족이어도 숙련 플레이로 이길 가능성을 무조건 없애는 설계는 확정하지 않았다.
- 강제 무적·단계별 피해 상한으로 최소 전투 시간을 만들지 않는다.
- 지속·장판 장점은 허용하되 틱·중첩·중복 명중·발동 고리는 검증한다.
- 바위와 나무 지형 사용.
- 회전 칼날의 안쪽 사각·명중 빈도는 필수 개조 없이 기능하도록 점검.

## 3. 성장 [D06–D08, D16]

- 처치 즉시 경험치. 땅에 경험치 아이템을 떨어뜨리지 않는다.
- 처치·지역 경험치 ×0.3 유지. 기존 기준 지급량에 한 번만 적용.
- 소수 경험치 누적.
- 경험치 ×0.3은 레벨업 횟수 ×0.3과 다르다.
- 승인된 속도를 과거 회차당 20~25회 같은 목표에 맞춰 되돌리지 않는다.
- 레벨업 중 전투 정지·입력 차단. 유효 후보가 충분하면 서로 다른 3택.
- 제시·시드·보류 선택 저장, 새로고침 재굴림 금지.
- 임무는 무료 성장 카드 추가보다 다음 자연 레벨업의 종류를 유도.
  - 정예 추적 → 보유 자동기술 레벨.
  - 제단 → 개조.
  - 봉인 → Q/E 계열.
  - 구출 → 장비·서비스·할인·휴식 등.
- 성장 예약의 세부 대기·중복·대체 정책은 구현자가 제안한 규칙과 구분.
  - v0.8 구현은 예약 1개, 충돌·후보 없음은 금화 대체.
  - 이는 사용자에게 명시된 구조 아래의 구현 선택이며 독립 검수상 후보 축소 버그 있음.
- 심층도 매번 무료 증강을 주지 않음. 장비·금화·변경권·성장 유도 등을 출발 전에 표시.

## 4. 시작 상태 [D22]

- 1일차 새벽, 5칸, 체력 100/100, 금화 60.
- 검격/관통창/회전 칼날 중 자동기술 하나 Lv1.
- 자동기술 나머지 2칸 빈칸, Q Lv1, E 없음.
- 장비 무기·갑옷·방패 모두 없음.
- 공용 공격 강화·개조·공용 증강·패시브 없음.
- 장비 없어도 자동 공격 정상 작동.
- 시작 전에 별도의 장비 선택 화면을 강요하지 않음.
- 세 시작 기술 모두 필수 개조 없이 초반 진행 가능해야 함.

## 5. 하루 계획 [D14–D15]

- 새벽/아침/점심/오후/저녁 5칸.
- 하루 출격 장소 기본 2곳. 오늘 출격 카드와 일반 탐험 목록을 통합.
- 첫 지역 일정안:
  - 1 숲/능선; 2 숲/습지; 3 능선/굴; 4 습지/굴;
  - 5 굴/심층; 6 이전 방문 지역 중 시드 1곳/심층; 7 최종 보스.
- 출격 비용은 명시된 1칸 또는 2칸.
- 구체적인 지역별 비용은 시험값. v0.8 구현: 숲·능선 1, 습지·굴·심층 2.
- 출발 시간대가 편성·사건·보상을 고정. 2칸 출격 중 숨은 변주 추가 금지.
- 중요한 시간 변화는 하루 시작에 알리고 하루 1~2개부터.
- 현재 장소와 시간에 실제 진입 가능한 이벤트만 제시.
- 방문 상인은 예정 시각부터 그날 끝까지 유지. 잠깐 왔다 사라지지 않음.
- 휴식 1칸 = 전부 회복. 체력이 가득해도 시간을 넘기는 데 사용 가능.
- 하루 종료 = 남은 칸 버림, 다음 날 정상 체력.
- 휴식·하루 종료로 보스 관문 건너뛰기 금지.
- 다음 날 장소·핵심 위험 미리보기.
- 상점·대장간·거점 장비 교체는 시간 무료.

## 6. 전투 종료·심층·패배 [D10, D17]

- 일반/정예/심층 전투는 모든 웨이브·대기 적 전멸로 종료.
- 정예 수는 정보. 하나 또는 정예 전부를 잡았다는 사실만으로 일반 전투 종료하지 않음.
- 제단·봉인·구출 등 특수 목표 즉시 종료 예외는 명시적으로 구분.
- 승리 후 귀환 또는 심층 1회. 시간 +1칸, 체력·미정산 전리품 유지.
- 심층 승리 후 귀환.
- 출격 중 전투가 시작되면 안전 탈출 없음. 포기 = 패배.
- 일반 패배:
  - 현재 출격의 미정산 금화·아이템 상실.
  - 남은 하루 상실, 다음 날 정상 체력으로 시작.
  - 이전 정산 재산·장비, 획득 경험치·선택한 성장 보존.
  - 랜덤 장비 파괴나 예전 상점 구매 취소 없음.
  - 다음 날 저체력 패널티 중복 없음.
- 보스 패배는 입장 스냅샷 복구·재도전. 일반 패배의 하루 상실과 분리.
- 입장 재산·장비·성장·소모 자원 상태를 반복 재도전으로 불릴 수 없어야 함.
- 임무 출격 후 심층 허용 여부, 임무 완료 장소의 일반 재방문 여부는 실제 UI·봇·명세를 맞춰 결정할 잔여 항목.

## 7. 장비 [D18–D20]

- 런 한정 무기/갑옷/방패 각 1칸.
- 장비 무기는 특수 효과를 주며 자동기술 3개를 대체하지 않음.
- 방패를 이유로 새 수동 버튼 추가 없음.
- 잉여 장비는 가방. 구매 후 장착/보관 선택.
- 거점 교체 무료, 출격 중 불가. 동일 장비 중복 구매 금지, 판매 가능.
- 자동기술/E는 가방 아이템이 아님.
- 장비·강화는 런 종료 시 소멸. 해금·제작법·도감의 영구 기록은 가능.
- 영구 능력치 노드·장비 파밍 시스템을 이번 범위에 추가하지 않음.

초기 12종 — 사용자가 채택한 시험안이며 최종 수치 승인 아님:

| 부위 | 이름 | 시험 효과와 주요 제한 |
|---|---|---|
| 무기 | 사냥꾼의 검 | 자동기술 직접 피해가 정예·보스에게 +15%; 지속/장판 제외 |
| 무기 | 개척자의 창 | 자동기술 사거리·범위 +12%; 회전 칼날 안쪽 사각을 키우지 않음 |
| 무기 | 잔불검 | 자기 화상·출혈 지속 +25%; 새 부여·틱 피해·중첩·장판 지속 증가 아님 |
| 무기 | 시간술사의 지팡이 | Q 안 대상에게 자동기술 직접 피해 +20%; 지속/장판 제외, 중복 Q 배율 없음 |
| 갑옷 | 여행자의 경갑 | 이동 +8% |
| 갑옷 | 수호자의 갑옷 | 전투 시작 보호막 15 |
| 갑옷 | 생명력의 외투 | 최대 체력 +20; 장착 회복·탈착 회복 악용 없음 |
| 갑옷 | 원정대의 갑옷 | 전투 승리마다 회복 8, 정산당 한 번. 귀환 전용 아님 |
| 방패 | 철벽 방패 | 경감 전 1회 직접 타격이 최대 체력 20% 이상이면 그 피해 -25%; 지속 제외 |
| 방패 | 비상 방패 | 체력 30% 이하 보호막 20, 전투당 1회; 소급 방어·부활 없음 |
| 방패 | 시전자의 방패 | E 사용 시 3초 보호막 8, 자체 재사용 10초, 누적 없음 |
| 방패 | 시간의 방패 | Q 안 공격자가 주는 직접 피해 -20%; 잔류 바닥 피해 제외 |

적용 대상·피해 출처·갱신·중첩을 명확히 한다. 추가 발동의 무한 순환 금지.
현재 빌드에 적용 대상이 없는 효과는 간단하게 표시.

## 8. 상점·대장간 [D21–D24]

- 하루 시드 고정 재고, 재접속·재진입 재굴림 없음.
- 기본 장비 2 + 자동기술 또는 E 1.
- 방문 상인 별도 재고. 날짜만으로 같은 상품 가격 증가하지 않음.
- 대장간 고정 서비스, 보스 뒤 다음 강화 개방.
- 금화 중심. 기본 기능을 재료 반복 파밍 뒤에 잠그지 않음.
- 장비 개별 강화는 후순위.

시험 가격:
| 항목 | 금화 |
|---|---:|
| 장비 무기 구매/판매 | 140 / 35 |
| 갑옷·방패 각각 구매/판매 | 120 / 30 |
| 빈 슬롯 자동기술·E 획득 각각 | 180 |
| 같은 자동기술 개조 하나 변경 | 140 |
| 같은 E 변형 변경 | 140 |
| 공용 공격 강화 +1 / +2 / +3 | 90 / 160 / 240 |

- 강화 +1 시작부터, +2 첫 보스 뒤, +3 두 번째 보스 뒤.
- 구체적인 공용 공격 배율 +10/+20/+30%는 v0.8 구현자의 시험값. 사용자 최종 승인과 구분.
- 기술 교체: 120 + (현재 Lv−1)×40 + 개조·변형 수×80.
- 예: 자동 Lv1 120 / Lv3 개조1 280 / Lv5 개조2 440; E Lv3 무변형 200 / 변형1 280.
- 교체 시 레벨·개조 개수 보존, 새 기술의 개조 다시 선택.
- 이전 기술은 가방에 남지 않음.
- 최종 확정 전에 기존 기술·개조·금화·이용권을 훼손하지 않음.
- 취소 시 완전 원복. 공용 증강 적용 대상 상실을 확정 전에 표시.
- 정상 성공 하루 수입 180~240은 휴식 1회 포함 첫 경제 시험 목표.
- 첫날에 모든 구매를 끝내지 않고 장비/강화/새 기술 저축 사이 선택.
- 이 목표가 실제 구현에서 달성됐다는 독립 확인은 아직 없음.

## 9. UI와 통계 [D11, D25–D26]

- 기본: 이름·핵심 효과/보상·비용·현재 상태·주요 위험.
- 나머지는 상세, 밑줄 용어, 필요 시 중첩 설명.
- PC hover 설명, 클릭 고정, 부모→자식 이동 시 유지.
- 모바일 탭·뒤로 이동, 화면 경계 보호, 깊어지면 패널.
- 설명을 의도적으로 열어 읽는 동안 전투 정지. 단순 hover마다 자동 정지하지 않음.
- 키보드 접근·입력 복구.
- 수치·용어는 실제 데이터와 연결. 핵심 약점은 상세 속에 숨기지 않음.
- 개발 설정은 정상 흐름과 분리. 실제 버전·런 설정은 쉽게 확인 가능.

피해 통계:
- 기술별 총 유효 피해·점유율·DPS.
- 직접/화상·출혈/장판/추가 발동 원천 추적.
- 파생 피해를 기술에 귀속해도 합계에서 중복하지 않음.
- 실제 체력 감소만, 초과 피해 제외.
- DPS 분모: 그 기술을 보유한 실제 전투 시간. 획득 전·제거 후·메뉴·정지 제외.
- 실제로 공격한 순간만 분모로 사용하지 않음.
- 일반/정예 및 보스 상세, 보스 실패 시도와 성공 구분.
- 방어·감속·회복은 피해 DPS에 넣지 않음.
- 저장·재접속 이어짐.

## 10. Godot 전환 범위 [D29–D30]

- Godot을 최종 개발 방향으로 삼고 첫 실행판부터 확인한다.
- 별도 프로젝트, 공식 안정판 4.x, GDScript, 우선 Compatibility.

# 설계 변경 이력

기록일: 2026-09-07. 정확한 과거 날짜가 없는 항목은 버전·대화 순서로만 표시한다.
D 번호는 이번 정리에서 부여한 식별자이며 실제 당시의 발행 번호가 아니다.
초기 제안과 폐기안이 구현된 적이 있었다고 가정하지 않는다.
현재 규칙은 GAME_SPEC(통합 전 CURRENT_DESIGN_DRAFT), 현재 수치는 ASSUMPTIONS를 따른다.

## 변경 기록 형식

향후 추가할 때:
- ID / 실제 결정일과 시간대 / 기록일.
- 설계 상태와 결정 주체.
- 이전 → 이후.
- 바꾼 이유와 사용자 발언 또는 검수 증거.
- 대체하는 결정 ID.
- 적용 커밋·검증 커밋·미해결 항목.
날짜·근거·커밋을 모르면 미상으로 남긴다.
같은 결정이 구현되면 기존 기록의 적용 근거를 추가하고, 다른 결정으로 바뀌면 새 ID를 부여한다.

## D01 — 旧 전투 → 실시간 액션

- 시점: 초기 액션 전환 논의·정확한 날짜 미상.
- 상태: 사용자 합의.
- 변경: 타임라인 중심 전투에서 자동 공격·이동·회피가 있는 액션으로 전환.
- 이유·근거: 타임라인을 파훼·우회하는 재미와 상태 가시성이 약했고 성장 기대도 없었다. 사용자가 “전투 자체를 뱀서라이크로 하는건 어때?” 제안 후 실제 액션판에 “일단 재미는 있어”라고 평가.
- 현재 영향·검증: HTML 액션판 구현·사용자 플레이 확인. Godot에서도 핵심 전투 의도 보존.

## D02 — 첫 구현 도구로 HTML 선택

- 시점: 첫 액션 프로토타입·정확한 날짜 미상.
- 상태: 당시 구현 선택; Godot 전환으로 대체 중.
- 변경: 원격 Linux 환경에서 Canvas·JavaScript·단일 HTML을 사용.
- 이유·근거: 기존 Windows 프로젝트에 접근할 수 없고 브라우저 실행·배포가 편하다는 구현자의 결정. 엔진 가격 때문이 아니었음.
- 현재 영향·검증: D29에서 후속 개발 방향 변경. HTML은 비교 자료.

## D03 — 자동 공격 구성과 수동 슬롯

- 시점: 성장 체계 초기 논의·날짜 미상.
- 상태: 사용자 합의.
- 변경: 자동 공격 기술 최대 3개, Q/E 수동기술, Space 회피.
- 이유·근거: 사용자: “무기하나에 특수키 감속장하나면 너무 단조로울것같아”, 이후 “총 무기는 3개, 수동기술은 2개. 그리고 스페이스바.”
- 현재 영향·검증: 이후 D19에서 여기의 무기를 자동기술로 명칭 분리. 자동기술 Lv5/개조2, Q/E Lv3/변형1의 합의안 보존.

## D04 — 회피 성공 보상 중심 빌드 배제

- 시점: 감속장·회피 성장 논의·날짜 미상.
- 상태: 사용자 합의.
- 변경: 회피는 조작 수단으로 유지하되 성공 판정 보상 반복을 핵심 성장 축으로 삼지 않음.
- 이유·근거: 사용자: “회피성공 이거는 좀 안좋은거같아 컨셉이”. 감속장은 “이거 괜찮다”라고 평가.
- 현재 영향·검증: 다른 개조를 추가할 때 폐기된 축을 무심코 부활시키지 않음.

## D05 — 적 행동 다양성과 보스 3개

- 시점: 런 구조 논의·날짜 미상.
- 상태: 사용자 합의; 플레이 시간은 미확정.
- 변경: 행동이 다른 기본 적 10~12종을 역할별 편성. 보스 3개와 관문 희귀 선택 보상.
- 이유·근거: 사용자: “몬스터 특징 정해놓고 적당히 배치”, “보스3마리는 … 전체적인 플레이타임이 몇분정도냐 를 기준으로”. 재료·패시브만을 위해 나가는 반복 노동을 싫어함.
- 현재 영향·검증: 3/5/7일 관문 기본안. 몇 분이 정답인지 봇 시간만으로 확정하지 않음.

## D06 — 경험치는 자동 지급

- 시점: 성장 슬롯 합의 시점·날짜 미상.
- 상태: 사용자 합의.
- 변경: 처치 즉시 경험치 지급, 구슬·자석 시스템 없음.
- 이유·근거: 사용자: “경험치는 땅에 떨어지게하지말자 우리는 죽이면 무조건 경험치얻음”.
- 현재 영향·검증: UI나 엔진 변경과 관계없이 유지.

## D07 — 빠른 성장·낮은 적 체력 문제 분리

- 시점: v0.5~v0.7 피드백.
- 상태: 사용자 문제 제기; 수치는 시험.
- 변경: 경험치 속도와 적 생존·공격 기회를 별도로 측정하기로 함.
- 이유·근거: 사용자: “레벨업이 너~~무 빨라”, “적이 너무 체력이 낮아서 빨리죽어”, 그래서 선택을 생각 없이 한다고 지적.
- 현재 영향·검증: 체력·경험치 후보를 만들었으나 후보 존재와 기본 적용은 D27에서 혼동 발견.

## D08 — 경험치 ×0.3 유지

- 시점: v0.7.2 직접 완주 후·정확한 날짜 미상.
- 상태: 사용자 합의.
- 변경: 처치·지역 경험치 ×0.3 시험 속도를 유지. 과거 목표 레벨업 횟수에 맞춰 다시 가속하지 않음.
- 이유·근거: 사용자: “지금의 30%정도로 줄여도돼”, 이후 “레벨업 정도는 지금이 훨씬 나아. 이게 맞고”.
- 현재 영향·검증: 경험치 배율과 실제 레벨업 횟수는 다름. 적 수·보상 경로 변경 후에도 실제 속도 재측정.

## D09 — 시작 기술별 불균형 점검

- 시점: 창 플레이 및 v0.7.2 회전 칼날 완주 후.
- 상태: 사용자 문제 제기; 균형값 미승인.
- 변경: 같은 투자량으로 화력·안전성·명중 비교. 회전 칼날은 사각·접촉부터 점검.
- 이유·근거: 사용자: “창 … 사거리가 너무 길더라고”, “회전칼날이 너무쓰레기임. 초반에 진행이 잘 안될정도.”
- 현재 영향·검증: v0.8 칼날 8/0.45→10/0.35는 구현자가 채택한 시험값(문서 기록 2026-09-07). 사람의 개선 승인 없음.

## D10 — 일반 전투 종료 = 모든 적 처치

- 시점: v0.7.1 이후, v0.7.2 반영 보고.

- 이유·근거: 사용자: “정예처치가 아니라 모든적 처치여야 라운드 끝나는게 맞다”.
- 현재 영향·검증: 대기·웨이브 포함. 제단·봉인·구출 목표 완료 예외는 후속 구현 지시에서 명시적으로 구분.

## D11 — 기본 화면의 긴 설명 축소

- 시점: 출격 화면 첫 플레이 피드백부터 지속.
- 상태: 사용자 합의.
- 변경: 카드는 핵심 요약과 상세 보기. 개발 설정은 정상 흐름에서 분리.
- 이유·근거: 사용자: “선택할수 있는게 너무많아”, “글씨가 너무많음”, “상세보기 ... 누르면 설명”.
- 현재 영향·검증: v0.8에서도 시작 화면 노출·표시 수치 불일치가 남음(F6). D25의 중첩 설명으로 확장.

## D12 — 보스 맞공격과 준비 부족 빌드 시험

- 시점: 3일차 성장 중단 완주를 반복한 뒤.
- 상태: 사용자 문제 제기; 목표 방향 합의.
- 변경: 정지/기본 회피/숙련 봇, 초반 중단/정상 준비 빌드를 구분해서 보스 위협 점검.
- 이유·근거: 사용자: “보스 패턴이 뭔지 보지도 못하고”, “보스랑은 그냥 맞다이쳐도 개바름”.
- 현재 영향·검증: 보스 체력만 증가하거나 강제 무적·피해 상한으로 시간을 고정하지 않음. 적절한 압박은 사람 판단 필요.

## D13 — 날짜가 지날수록 적 위협 변화

- 시점: v0.7.2 완주 뒤 하루 재설계.

- 변경: 날짜별 편성·지원·후열·측면·장판 조합으로 후반 대응을 요구.
- 이유·근거: 사용자: “몬스터들이 세지는게 없다보니까 나중가면 너무 쉬움”.

## D14 — 하루 장소 2곳으로 압축

- 시점: 날짜별 장소 제한 논의.
- 상태: 사용자 합의한 구현안.
- 변경: 날짜별 기본 두 장소, 오늘 카드와 일반 탐험 통합.
- 이유·근거: 사용자: “날짜별로 들어갈수 있는 장소를 좀 제한”, “던전 선택지가 너무많다보니까 글씨를 그냥 안읽게”.
- 현재 영향·검증: 정해진 지역 일정은 첫 배치안. 임무 완료 뒤 재방문 정책은 UI·봇 충돌을 해결하며 명시해야 함.

## D15 — 5시간을 5개 시간대로 구체화

- 시점: 하루 운영 논의.
- 상태: 사용자 합의.
- 변경: 새벽/아침/점심/오후/저녁, 출발 시점 조건 고정. 휴식·상점·방문 상인 규칙 정리.
- 이유·근거: 사용자: “5시간이 새벽 아침 점심 오후 저녁”, “시간대별로 몬스터나 이벤트에 변화”.

## D16 — 임무 보상으로 성장 가속 우회 방지

- 시점: 하루·보상 재설계; 종합 지시문에 포함.
- 상태: 사용자 합의한 구현안; 예약 세부는 구현 선택.
- 변경: 매번 무료 전투력 3택보다 다음 자연 레벨업의 종류를 유도. 심층 보상 다양화.
- 이유·근거: 경험치만 늦춰도 임무·심층 무료 강화가 많이 남으면 선택 속도 문제가 반복됨.
- 현재 영향·검증: 예약 1개·충돌 시 금화는 Claude 세부 구현. F3 후보 축소 오류와 금화 정산 시점은 검증 필요.

## D17 — 패배 시 출격 전리품 + 남은 하루 상실

- 시점: 패널티 논의.
- 상태: 사용자 합의.
- 변경: 현재 출격 미정산 금화·아이템과 남은 하루를 잃고 다음 날 정상 체력. 기존 재산·성장 보존.
- 이유·근거: 사용자는 약한 패널티를 싫어했으나 '그날 번 돈으로 이미 산 아이템' 추적 문제를 제기. 랜덤 장비 상실도 아이디어로 제시했지만 최종 채택하지 않음.
- 현재 영향·검증: 런 전체 재산 롤백·랜덤 장비 파괴·다음 날 저체력 중복 패널티는 미채택. 보스는 스냅샷 재도전으로 분리.

## D18 — 장비는 런 한정 물건

- 시점: 장비 인벤토리·영구 성장 논의.

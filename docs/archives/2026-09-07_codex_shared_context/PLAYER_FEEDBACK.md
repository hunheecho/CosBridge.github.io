# 사용자 플레이 확인 — Godot 0.3.1

기록일: 2026-09-07. 저장소 밖 공유 문서 초안. 구현자가 공식 변경 이력·시험값·검증 상태에 병합할 자료다.

## D33 — 첫 전투 25마리 편성의 체감 채택

- 결정 주체: 사용자, 직접 플레이 후 평가.
- 사용자 원문: “플레이해봤어. 지금 느낌 아주 좋다. 적 갯수도 괜찮고 난이도도 적절한것같아. 늑대 짧은공격과 돌진 비율도 아주 좋아. 굿”
- 상태: 해당 첫 전투 설정에 대한 사용자 긍정 평가. 이후 변경의 비교 기준으로 보존.
- 근거: 사용자 첨부 실제 플레이 화면과 발언. 화면은 전투 중이며, 승리·완주·플레이 횟수·시드는 확인할 수 없다.

화면 하단에서 확인되는 적용 설정:
- godot-0.3.1
- 검격 12 / 0.55초
- 늑대 체력 30.0
- 물기 피해 12.0 / 돌진 피해 12.0
- 5배: 전체 25마리 / 동시 12마리
- 동시 돌진 2마리
- 회피 거리 조절 70~150 / 재사용 1.5초
- 봇 꺼짐

판정 범위:
- 긍정 평가: 현재 전투 느낌, 적 개체 수, 현재 난이도, 짧은 물기와 돌진의 비율.
- 확대하지 않는 범위: 50마리 편성, 다른 자동기술, 다른 적 조합, 보스, 회차 전체 성장·경제, 목표 플레이타임.
- 회피 개별 수치 각각을 독립 비교한 결과로 기록하지 않는다. 현재 조합 전체에 대한 평가다.

유지할 기준:
- 이 설정을 비교용으로 재현할 수 있게 보존한다.
- 봇 명중률 등의 단일 수치만 보고 검격 넉백·물기 사거리·돌진 빈도를 자동 조정하지 않는다.
- 임시 그래픽·타격 반응을 추가할 때 전투 규칙과 위 수치를 함께 변경하지 않는다.
- 신규 적·무기·편성은 현재 늑대 전투와 별도 비교한다.
- 새 이름은 여전히 미정이며 이 기록으로 가칭을 확정하지 않는다.
